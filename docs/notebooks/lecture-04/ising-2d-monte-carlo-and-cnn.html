The 2D Ising model and a CNN

This notebook gathers everything the lecture shows about the Ising model in a form that runs on a laptop CPU. We first set up the model and a Metropolis sampler implemented in JAX, using jit for compilation, vmap for many chains in parallel and lax.scan for the loop over sweeps. With it we generate datasets of configurations for \(L = 10, 20, 30, 40, 50\), saved to data/ising_L{L}.npz, and compare their magnetisation and energy with Onsager’s exact results. We then draw the pictures used in the lecture — a 1D chain, snapshots across \(T_c\), the dataset — and finally train a convolutional neural network (CNN) only far from the transition, read off its confidence at every temperature, and follow how the resulting estimate of \(T_c\) depends on \(L\).

1. The model and the Metropolis sampler

Spins \(s_i=\pm1\) sit on an \(L\times L\) lattice with periodic boundaries, \(N=L^2\), with \[ H(\mathbf s) = -J\sum_{\langle i,j\rangle} s_is_j,\qquad p(\mathbf s)=\frac{e^{-\beta H(\mathbf s)}}{Z},\qquad Z=\sum_{\mathbf s}e^{-\beta H(\mathbf s)}, \] and \(J=k_B=1\). The observables per spin are \(m=\frac1N\sum_i s_i\) and \(e=H/N\).

The Metropolis algorithm proposes to flip a spin \(s_i\), which changes the energy by \(\Delta E = 2s_i\sum_{j\in{\rm nn}(i)}s_j\), and accepts the flip with probability \(\min(1,e^{-\beta\Delta E})\). Spins of one colour of a chessboard do not interact with each other, so all of them can be updated at once; one sweep is the black half followed by the white half. In JAX the sweep is a pure function, lax.scan repeats it, vmap runs many independent chains in parallel, and jit compiles the whole procedure.

Code 
def chessboard(L):
    x, y = np.meshgrid(np.arange(L), np.arange(L), indexing="ij")
    return jnp.asarray((x + y) % 2 == 0)

def sweep(s, key, beta, black):
    for colour in (black, ~black):
        key, sub = jax.random.split(key)
        nn = jnp.roll(s, 1, 0) + jnp.roll(s, -1, 0) + jnp.roll(s, 1, 1) + jnp.roll(s, -1, 1)
        accept = jax.random.uniform(sub, s.shape) < jnp.exp(-beta * 2.0 * s * nn)
        s = jnp.where(colour & accept, -s, s)
    return s, key

@partial(jax.jit, static_argnames=("n_equil", "n_samples", "n_between"))
def sample_chains(s0, keys, Ts, black, n_equil, n_samples, n_between):
    # every chain is cooled through Ts; at each T: n_equil sweeps, then n_samples stored every n_between sweeps
    def chain(s, key):
        def at_T(carry, T):
            step = lambda c, _: (sweep(c[0], c[1], 1.0 / T, black), None)
            carry, _ = lax.scan(step, carry, None, length=n_equil)
            def store(c, _):
                c, _ = lax.scan(step, c, None, length=n_between)
                return c, c[0].astype(jnp.int8)
            return lax.scan(store, carry, None, length=n_samples)
        return lax.scan(at_T, (s, key), Ts)[1]
    return jax.vmap(chain)(s0, keys)

2. The datasets

For every \(L\) we use 51 temperatures from 3.5 down to 1.0 (step 0.05). Forty independent chains are cooled through this grid, and at each temperature every chain contributes 5 configurations separated by \(2L\) sweeps, which gives 200 configurations per temperature. Each file stores

  • configs: int8, shape (n_T, 200, L, L), values \(\pm1\);
  • T: the temperatures (ascending);
  • the generation settings, so that every file documents itself.

Files already present in data/ are loaded; the others are generated, which takes several minutes for the largest lattices.

Code 
L_LIST = [10, 20, 30, 40, 50]

def generate(L, seed):
    k0, k1 = jax.random.split(jax.random.PRNGKey(seed))
    s0 = jnp.where(jax.random.bernoulli(k0, 0.5, (N_CHAINS, L, L)), 1.0, -1.0)
    out = sample_chains(s0, jax.random.split(k1, N_CHAINS), jnp.asarray(T_GRID[::-1], jnp.float32), chessboard(L),

    out = np.asarray(out)[:, ::-1]                                           # ascending T
    return out.transpose(1, 0, 2, 3, 4).reshape(len(T_GRID), N_CHAINS * N_SAMPLES, L, L)

3. Magnetisation and energy of finite lattices

The exact results for the infinite lattice serve as the reference. Below \(T_c\) the spontaneous magnetisation is \(M(T) = \left(1-\sinh^{-4}(2/T)\right)^{1/8}\) (Yang), and the energy per spin is \(u(T) = -\coth(2\beta)\left[1+\frac{2}{\pi}\left(2\tanh^2(2\beta)-1\right)K(\kappa)\right]\) with \(\kappa = 2\sinh(2\beta)/\cosh^2(2\beta)\) (Onsager). On finite lattices \(\langle|m|\rangle\) stays non-zero above \(T_c\) and the transition is rounded; in the figure this rounding should shrink as \(L\) grows.

Code 
def M_exact(T):
    T = np.asarray(T, float); out = np.zeros_like(T); low = T < TC
    out[low] = (1 - np.sinh(2 / T[low]) ** -4) ** 0.125
    return out

def u_exact(T):
    K = 1 / np.asarray(T, float); kap = 2 * np.sinh(2 * K) / np.cosh(2 * K) ** 2
    return -1 / np.tanh(2 * K) * (1 + 2 / np.pi * (2 * np.tanh(2 * K) ** 2 - 1) * ellipk(kap ** 2))

def energy(c):
    c = c.astype(np.float32)
    return -(c * np.roll(c, 1, -1) + c * np.roll(c, 1, -2)).mean((-1, -2))

4. Configurations across the transition

We start with a 1D chain. With \(h=0\) its bonds are independent: neighbours are parallel with probability \(p=e^{\beta J}/(e^{\beta J}+e^{-\beta J})\), so chains can be sampled exactly, bond by bond. The correlation length is \(\xi=-1/\ln\tanh(\beta J)\), and the three rows below, at \(T = 0.6\), \(1.0\) and \(5.0\), show domains whose length shrinks with temperature. 5. The critical temperature from CNN confidence

The network is trained only where the answer is clear: configurations with \(T<1.5\) get the label 0 (ordered), those with \(T>3\) the label 1 (disordered), and nothing between 1.5 and 3 is used for training.

The network, built with Flax NNX, consists of two blocks of a \(3\times3\) convolution with 16 channels (with periodic boundaries, like the lattice), ReLU and \(2\times2\) max pooling, followed by global average pooling, a dense layer of 32 ReLU units and 2 outputs with softmax; it is trained with the cross-entropy loss and Adam. Global average pooling makes the same network work for every \(L\).

After training we predict at every temperature. For one configuration the network gives \(p_1\), the probability of “disordered”, and its confidence is \(\max(p_0,p_1)\). This yields two estimates of \(T_c\): the temperature where the average confidence is lowest, and the temperature where \(\langle p_1\rangle_T\) crosses \(1/2\). Each lattice size is trained with three seeds, and the printout gives the mean and spread of both estimates.

Code 
class IsingCNN(nnx.Module):
    def __init__(self, *, rngs):
        self.c1 = nnx.Conv(1, 16, (3, 3), padding="CIRCULAR", rngs=rngs)
        self.c2 = nnx.Conv(16, 16, (3, 3), padding="CIRCULAR", rngs=rngs)
        self.d1 = nnx.Linear(16, 32, rngs=rngs); self.d2 = nnx.Linear(32, 2, rngs=rngs)
    def __call__(self, x):
        h = x[..., None]
        h = nnx.max_pool(nnx.relu(self.c1(h)), (2, 2), strides=(2, 2))
        h = nnx.max_pool(nnx.relu(self.c2(h)), (2, 2), strides=(2, 2))
        h = h.mean(axis=(1, 2))                                  # global average pooling
        return self.d2(nnx.relu(self.d1(h)))                     # logits

@nnx.jit
def train_step(model, opt, x, y):
    def loss_fn(m):
        return optax.softmax_cross_entropy_with_integer_labels(m(x), y).mean()
    loss, grads = nnx.value_and_grad(loss_fn)(model)
    opt.update(model, grads)
    return loss

@nnx.jit
def prob_disordered(model, x):
    return jax.nn.softmax(model(x))[:, 1]

T_MIN, T_MAX = 1.5, 3.0
def train_cnn(L, seed, epochs=8, batch=64):
    c = data[L]
    low, high = T_GRID < T_MIN, T_GRID > T_MAX
    X = np.concatenate([c[low].reshape(-1, L, L), c[high].reshape(-1, L, L)]).astype(np.float32)
    y = np.concatenate([np.zeros(c[low].shape[0] * c.shape[1], int), np.ones(c[high].shape[0] * c.shape[1], int)])
    model = IsingCNN(rngs=nnx.Rngs(seed)); opt = nnx.Optimizer(model, optax.adam(1e-3), wrt=nnx.Param)
    X, y = jnp.asarray(X), jnp.asarray(y); key = jax.random.PRNGKey(seed)
    for ep in range(epochs):
        key, k = jax.random.split(key); perm = jax.random.permutation(k, len(y))
        for i in range(0, len(y) - batch + 1, batch):
            train_step(model, opt, X[perm[i:i + batch]], y[perm[i:i + batch]])
    acc = float(((prob_disordered(model, X) > 0.5) == y).mean())
    return model, acc

def predict_all(model, L):
    c = jnp.asarray(data[L].reshape(-1, L, L), jnp.float32)
    return np.asarray(prob_disordered(model, c)).reshape(len(T_GRID), -1)

def estimates(p1):
    conf = np.maximum(p1, 1 - p1).mean(1); p1m = p1.mean(1)
    i = int(np.argmin(conf)); T_conf = T_GRID[i]
    j = int(np.where(np.diff(np.sign(p1m - 0.5)) != 0)[0][0])
    T_cross = T_GRID[j] + (0.5 - p1m[j]) * (T_GRID[j + 1] - T_GRID[j]) / (p1m[j + 1] - p1m[j])
    return conf, p1m, T_conf, T_cross

SEEDS = [0, 1, 2]
results = {}
t0 = time.time()
for L in L_LIST:
    runs = []
    for seed in SEEDS:
        model, acc = train_cnn(L, seed)
        runs.append((acc,) + estimates(predict_all(model, L)))
    results[L] = runs
    Tc_conf = np.array([r[3] for r in runs]); Tc_cross = np.array([r[4] for r in runs])
    print(f"L = {L:2d}: training accuracy {np.mean([r[0] for r in runs]):.4f}; T_c from the confidence minimum "
          f"{Tc_conf.mean():.3f} +- {Tc_conf.std():.3f}; from <p1> = 1/2: {Tc_cross.mean():.3f} +- {Tc_cross.std():.3f}"
          f"   ({time.time() - t0:.0f} s)")

fig, (axb, ax) = plt.subplots(2, 1, figsize=(7.0, 4.2), sharex=True, gridspec_kw=dict(height_ratios=[0.9, 3], hspace=0.08))
for a in (axb, ax):
    a.axvspan(T_GRID.min(), T_MIN, color=blue, alpha=0.18, lw=0); a.axvspan(T_MAX, T_GRID.max(), color=orange, alpha=0.22, lw=0)
axb.axvspan(T_MIN, T_MAX, color=grey, alpha=0.12, lw=0)
axb.text(1.25, 0.5, "training\nordered, $y=0$", ha="center", va="center", fontsize=8)
axb.text(2.25, 0.5, "no labels: prediction only", ha="center", va="center", fontsize=8)
axb.text(3.25, 0.5, "training\ndisordered, $y=1$", ha="center", va="center", fontsize=8); axb.axis("off")
TT = np.repeat(T_GRID, conf_all.shape[1])
ax.scatter(TT, conf_all.ravel(), s=2, c=np.where(p1.ravel() > 0.5, orange, blue), alpha=0.25)
ax.plot(T_GRID, conf, "k-", lw=2, label="average confidence")
ax.axvline(T_conf, color="k", ls="--", lw=1); ax.axvline(TC, color="red", ls=":", lw=1.5)
ax.text(T_conf + 0.03, 0.52, f"minimum at {T_conf:.2f}", fontsize=8); ax.set_xlabel("$T$"); ax.set_ylabel("confidence")
ax.legend(frameon=False, fontsize=8, loc="lower right")
fig.savefig(f"{OUT}/gen_Ising_confidence_vs_T.png", dpi=170, bbox_inches="tight"); plt.show()
