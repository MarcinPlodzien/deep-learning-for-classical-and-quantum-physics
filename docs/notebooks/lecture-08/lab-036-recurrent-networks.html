Lab 036 — Recurrent neural networks

A forecasting model receives the past of a measured signal \(s_1,s_2,\dots,s_k\) and returns the future values \(\tilde s_{k+\tau}\) for the leads \(\tau=1,\dots,50\). In Lecture 7 we characterised three physical signals and fitted linear models to them (Labs 033 and 034). The autoregressive (AR) model forecasts with a weighted sum of the last \(p\) values, and the nonlinear vector autoregression (NVAR) adds all their pairwise products. Both are ridge regressions on a fixed list of features of the past, and Lab 035 read them as linear maps on a fixed dictionary of observables, finite approximations of the Koopman operator. In this notebook we let the features be learned or generated by a dynamical system with a state. We follow one line of thought, and every model answers a limitation of the previous one.

We start with the same protocol and scores, and with the persistence, AR and NVAR baselines computed here, so that every model is scored on identical data (Sections 1 and 2). A multilayer perceptron (MLP) on the window of the last \(L\) values learns its nonlinear features from data, and with it we write the training loop that all networks share (Section 3). An echo state network (ESN) keeps the history in the state of a fixed random dynamical system and trains only a linear readout. This reservoir computing scheme sits between NVAR and fully trained networks, and we test it on memory and nonlinearity benchmarks before forecasting (Section 4). The recurrent neural network (RNN) trains the recurrence itself, and its gradients pass through a product of Jacobians that either vanishes or explodes (Section 5). The long short-term memory (LSTM) and the gated recurrent unit (GRU) add gated memory paths that control this product (Section 6). We implement all three cells in flax.nnx and check them against the library cells (Section 7). We then train them and discuss the practical side, namely windows and batching, scaling, initialisation, gradient clipping, early stopping, the choice of window and hidden size, and the spread over random seeds (Section 8). Finally we compare all models on all signals (Section 9) and run the networks on their own predictions, which exposes the difference between training with the true past and generating a signal (Section 10).

The implementation uses JAX. The networks are flax.nnx modules, the optimiser comes from optax, the time loop of every recurrent model is a jax.lax.scan, and every training epoch is one jit-compiled program. For the reservoir we show the JAX implementation next to the ReservoirPy library.

1. Signals and forecasting protocol

We use the five signals of Lecture 7, generated by the same code. The first coordinate of the Lorenz-63 system (\(\sigma=10\), \(\rho=28\), \(\beta=8/3\)) is integrated by the fourth-order Runge–Kutta method (RK4) and sampled every \(\Delta t=0.02\). The Mackey–Glass delay equation \(\dot s=\beta s(t-\tau_{\rm MG})/(1+s(t-\tau_{\rm MG})^{10})-\gamma s\) with \(\beta=0.2\), \(\gamma=0.1\) is sampled once per time unit for three delays. The delay \(\tau_{\rm MG}=15\) gives a limit cycle, and \(\tau_{\rm MG}=25\) and \(35\) give chaos. The attractor at 35 has the higher dimension, but nearby states separate more slowly there than at 25, so it is the easier of the two to forecast over 50 steps. The Santa Fe laser series (data set A) is the measured intensity of a far-infrared NH\(_3\) laser, regular pulsations whose amplitude grows until it collapses at irregular times. Signals are generated in float64.

Code 
# Reference signal generators shared by the time-series notebooks

# Lorenz-63: sigma=10, rho=28, beta=8/3; RK4 with h=0.01, sampled every 2 steps (dt=0.02);
# initial state (1,1,1), first 50 time units discarded; we keep the x component.
def lorenz_rhs(u, sigma=10.0, rho=28.0, beta=8.0/3.0):
    x, y, z = u
    return jnp.array([sigma*(y - x), x*(rho - z) - y, x*y - beta*z])

def rk4_step(f, u, h):
    k1 = f(u); k2 = f(u + 0.5*h*k1); k3 = f(u + 0.5*h*k2); k4 = f(u + h*k3)
    return u + h/6.0*(k1 + 2*k2 + 2*k3 + k4)

@partial(jax.jit, static_argnums=(0, 1, 2))
def lorenz_trajectory(n_samples, sub=2, n_discard=2500, h=0.01):
    """Returns array (n_samples, 3) sampled every `sub` RK4 steps (dt = sub*h)."""
    def one_sample(u, _):
        u = jax.lax.fori_loop(0, sub, lambda i, v: rk4_step(lorenz_rhs, v, h), u)
        return u, u
    u0 = jnp.array([1.0, 1.0, 1.0])
    u, _ = jax.lax.scan(one_sample, u0, None, length=n_discard)
    _, traj = jax.lax.scan(one_sample, u, None, length=n_samples)
    return traj

# Mackey-Glass: dx/dt = beta x(t-tau)/(1+x(t-tau)^n) - gamma x, beta=0.2, gamma=0.1, n=10;
# RK4 with h=0.1, the delayed value at half steps by linear interpolation, constant history
# x=1.2 on [-tau, 0], first 3000 fine steps discarded, every 10th point kept (unit sampling).
def mackey_glass(tau, n_samples, h=0.1, x0=1.2, transient=3000, every=10,
                 beta=0.2, gamma=0.1, n=10):
    lag = int(round(tau / h))
    f = lambda x, xd: beta * xd / (1.0 + xd**n) - gamma * x
    def step(buf, _):
        # buf = (x[i-lag], ..., x[i]) : the delay window, length lag+1
        x, xd0, xd1 = buf[-1], buf[0], buf[1]
        xdh = 0.5 * (xd0 + xd1)
        k1 = f(x, xd0); k2 = f(x + 0.5*h*k1, xdh); k3 = f(x + 0.5*h*k2, xdh); k4 = f(x + h*k3, xd1)
        xn = x + h/6.0*(k1 + 2*k2 + 2*k3 + k4)
        return jnp.concatenate([buf[1:], xn[None]]), xn
    n_steps = transient + n_samples * every
    _, xs = jax.lax.scan(step, jnp.full(lag + 1, x0), None, length=n_steps)
    x = np.concatenate([np.full(lag + 1, x0), np.asarray(xs)])
    return x[transient::every][:n_samples]

Every signal has \(N=4000\) samples, split in time order. The first 3000 form the training block, and its last 500 samples serve as validation. The final 1000 samples are the test block. Each signal is rescaled to \([0,1]\) with the minimum and maximum of the fitting part of the training block (the first 2500 samples) only, so the validation and test blocks may slightly exceed this interval.

A forecast is made at an origin \(k\) from the past \(s_k,s_{k-1},\dots\) and returns all leads \(\tau=1,\dots,50\) at once. This is direct forecasting, one output per lead, and the model never sees its own predictions. Every model of this notebook reads at most the window of the last \(L=64\) values, \[\mathbf v_k=(s_{k-L+1},\dots,s_{k-1},s_k)\in\mathbb R^{L},\qquad \mathbf y_k=(s_{k+1},\dots,s_{k+50})\in\mathbb R^{50}.\] The origins are chosen so that no target crosses a block boundary. Fitting uses the origins \(k=63,\dots,2449\) (targets inside the first 2500 samples), validation the origins \(k=2499,\dots,2949\) (targets inside the validation block), and testing the origins \(k=2999,\dots,3949\) (targets inside the test block). A window may reach back into an earlier block, since the inputs are past values that are known at the time of the forecast.

Scores

The scores are those of Lecture 7. For each lead \(\tau\) we compare the predictions \(\tilde s_{k+\tau}\) with the true values \(s_{k+\tau}\) over the \(n\) test origins. The normalised mean-square error \(\mathrm{NMSE}(\tau)=\langle(\tilde s_{k+\tau}-s_{k+\tau})^2\rangle/\mathrm{Var}(s_{k+\tau})\) measures the error in units of the signal variance, and the Pearson coefficient \(r(\tau)\) measures how well the shape of the prediction follows the truth. The forecast capacity \(C(\tau)=r(\tau)^2\) lies in \([0,1]\). Its sum over the 50 leads, the total capacity \(C_{\rm tot}=\sum_{\tau=1}^{50}C(\tau)\le 50\), summarises a whole curve, and the skill horizon \(\tau_{1/2}\) is the first lead with \(C(\tau)<0.5\). A capacity close to 1 with a large NMSE means that the shape is right and the scale is wrong, which is why both are reported.

Code 
@jax.jit
def nmse_and_r(pred, true):
    # pred, true: (n, TAU_MAX); averages over the n origins, one value per lead
    err = jnp.mean((pred - true) ** 2, axis=0) / jnp.var(true, axis=0)
    pc, tc = pred - pred.mean(0), true - true.mean(0)
    r = jnp.sum(pc * tc, 0) / jnp.sqrt(jnp.sum(pc ** 2, 0) * jnp.sum(tc ** 2, 0))
    return err, r

def score(pred, true):
    # dictionary with NMSE(tau), r(tau), C(tau) = r^2, C_tot and the skill horizon tau_1/2
    e, r = (np.asarray(a) for a in nmse_and_r(jnp.asarray(pred, jnp.float64), jnp.asarray(true, jnp.float64)))
    C = r ** 2
    below = np.nonzero(C < 0.5)[0]
    return dict(nmse=e, r=r, C=C, Ctot=float(C.sum()), tau_half=int(below[0] + 1) if len(below) else None)

2. Persistence, AR and NVAR baselines

Persistence repeats the last value, \(\tilde s_{k+\tau}=s_k\). It needs no fitting and sets the floor that any model must beat. The direct AR model of order \(p\) and the NVAR model are ridge regressions on features of the delay vector \(\mathbf d_k=(s_k,s_{k-1},\dots,s_{k-p+1})\), \[\tilde{\mathbf y}_k=W^\top\boldsymbol\phi(\mathbf d_k)+\mathbf b,\qquad \boldsymbol\phi_{\rm AR}=\mathbf d_k,\qquad \boldsymbol\phi_{\rm NVAR}=\big(\mathbf d_k,\ \{s_{k-i}s_{k-j}\}_{0\le i\le j<p}\big),\] where \(W\) has one column per lead and NVAR has \(p+p(p+1)/2\) features [Gauthier et al., Nat. Commun. 12, 5564 (2021), doi:10.1038/s41467-021-25801-2]. Ridge regression minimises \(\sum_k\|\tilde{\mathbf y}_k-\mathbf y_k\|^2+\beta\|W\|^2\). With centred features \(\Phi_c\) and centred targets \(Y_c\) the solution is \[W=(\Phi_c^\top\Phi_c+\beta I)^{-1}\Phi_c^\top Y_c,\qquad \mathbf b=\bar{\mathbf y}-W^\top\bar{\boldsymbol\phi},\] so the intercept \(\mathbf b\) is not penalised. The order \(p\) and the ridge strength \(\beta\) are chosen by the largest \(C_{\rm tot}\) on the validation origins. All linear models are treated in detail in Lecture 7. Here they serve as reference points, computed with the same origins as the networks.

Code 
def ridge_fit(F, Y, beta):
    # centred ridge regression, F: (n, d) features, Y: (n, m) targets -> W (d, m), b (m,)
    fm, ym = F.mean(0), Y.mean(0)
    Fc, Yc = F - fm, Y - ym
    W = jnp.linalg.solve(Fc.T @ Fc + beta * jnp.eye(F.shape[1]), Fc.T @ Yc)
    return W, ym - fm @ W

def delay_features(s, ks, p):
    # rows (s_k, s_{k-1}, ..., s_{k-p+1})
    return s[ks[:, None] - np.arange(p)[None, :]]

def nvar_features(s, ks, p):
    # delay vector and all quadratic monomials s_{k-i} s_{k-j}, i <= j
    d = delay_features(s, ks, p)
    iu, ju = np.triu_indices(p)
    return np.concatenate([d, d[:, iu] * d[:, ju]], axis=1)

3. Multilayer perceptron on the delay window

The Santa Fe laser shows the limits of a linear model. The intensity grows over many pulsations and then collapses, so the same recent values can be followed either by a larger pulse or by a collapse. The map from the past window to the future folds the reconstructed attractor, and a weighted sum of past values cannot represent a fold. The scatter plots below compare the true value with the AR forecast five steps ahead. The AR model underestimates the large pulses and spreads the small ones.

A one-hidden-layer perceptron on the window \(\mathbf v_k\) computes \[\tilde{\mathbf y}_k=W_2\tanh(W_1\mathbf v_k+\mathbf b_1)+\mathbf b_2,\qquad W_1\in\mathbb R^{n_{\rm hid}\times L},\ W_2\in\mathbb R^{50\times n_{\rm hid}}.\] The universal approximation theorem guarantees that such a network with enough hidden units approximates any continuous function on a compact set to any accuracy [Cybenko, Math. Control Signals Syst. 2, 303 (1989), doi:10.1007/BF02551274; Hornik, Neural Netw. 4, 251 (1991), doi:10.1016/0893-6080(91)90009-T]. The theorem says nothing about how many units are needed or whether gradient descent finds the weights. The network is a nonlinear representation of the past, \(\tanh(W_1\mathbf v_k+\mathbf b_1)\), followed by a linear map to the future. Here, unlike in NVAR, the representation is learned. We use \(n_{\rm hid}=64\) hidden units.

Training loop

All networks of this notebook are trained by one function. The training set consists of the windows \((\mathbf v_k,\mathbf y_k)\) for the fitting origins, an array of shape \((n_{\rm fit},L,1)\) of inputs and \((n_{\rm fit},50)\) of targets. Neighbouring windows overlap in \(L-1\) values, so they are far from independent samples, and we shuffle them at every epoch and cut them into minibatches of 128 windows. The loss is the mean-square error over the minibatch and all 50 leads, \[\mathcal L=\frac{1}{50\,B}\sum_{k\in\text{batch}}\|\tilde{\mathbf y}_k-\mathbf y_k\|^2 .\] The Adam optimiser with learning rate \(5\times10^{-3}\) updates the weights. Before every update the gradient is rescaled when its Euclidean norm over all parameters exceeds 1. This gradient clipping [Pascanu et al., ICML (2013), arXiv:1211.5063] protects against the rare very large gradients of recurrent networks discussed in Section 5. After every epoch we compute the loss on the validation windows. We keep the parameters with the lowest validation loss and stop when it has not improved for 20 epochs, at most after 250 epochs. This early stopping is the only protection against overfitting that we use, and the test block is never looked at during training.

Technically, nnx.split separates a model into its structure (graphdef) and its parameters, which makes the loss a pure function of the parameters. jax.value_and_grad returns loss and gradient, optax.chain(clip_by_global_norm, adam) turns the gradient into an update, and one jax.lax.scan over the minibatches forms an epoch that jax.jit compiles once.

Code 
BATCH, LR, CLIP, MAX_EPOCHS, PATIENCE = 128, 5e-3, 1.0, 250, 20

def n_params(model):
    return int(sum(x.size for x in jax.tree.leaves(nnx.state(model, nnx.Param))))

def fit_network(model, data, seed=0, epochs=MAX_EPOCHS, patience=PATIENCE, verbose=True):
    # data = (U_fit, Y_fit, U_val, Y_val), inputs of shape (n, L, 1), float32
    Uf, Yf, Uv, Yv = data
    graphdef, params, rest = nnx.split(model, nnx.Param, ...)
    tx = optax.chain(optax.clip_by_global_norm(CLIP), optax.adam(LR))
    opt_state = tx.init(params)
    n = Uf.shape[0]; n_batches = n // BATCH

    def loss_fn(p, U, Y):
        return jnp.mean((nnx.merge(graphdef, p, rest)(U) - Y) ** 2)

    @jax.jit
    def epoch(p, opt_state, key):
        idx = jax.random.permutation(key, n)[: n_batches * BATCH].reshape(n_batches, BATCH)
        def step(carry, ib):
            p, opt_state = carry
            loss, g = jax.value_and_grad(loss_fn)(p, Uf[ib], Yf[ib])
            gnorm = optax.global_norm(g)                  # norm before clipping
            upd, opt_state = tx.update(g, opt_state, p)
            return (optax.apply_updates(p, upd), opt_state), (loss, gnorm)
        (p, opt_state), (losses, gnorms) = jax.lax.scan(step, (p, opt_state), idx)
        return p, opt_state, losses.mean(), gnorms, loss_fn(p, Uv, Yv)

    key = jax.random.key(seed)
    hist = dict(train=[], val=[], gnorm=[], clipped=[])
    best_val, best_params, best_ep, t0 = np.inf, params, 0, time.time()
    for ep in range(epochs):
        key, sub = jax.random.split(key)
        params, opt_state, l_tr, gn, l_va = epoch(params, opt_state, sub)
        gn = np.asarray(gn)
        hist["train"].append(float(l_tr)); hist["val"].append(float(l_va))
        hist["gnorm"].append(float(np.median(gn))); hist["clipped"].append(float(np.mean(gn > CLIP)))
        if float(l_va) < best_val:
            best_val, best_params, best_ep = float(l_va), params, ep
        elif ep - best_ep >= patience:
            break
    hist = {k: np.array(v) for k, v in hist.items()}
    hist.update(best_epoch=best_ep + 1, epochs_run=ep + 1, time=time.time() - t0, best_val=best_val)
    if verbose:
        print(f"    {ep + 1:3d} epochs, best validation loss {best_val:.2e} at epoch {best_ep + 1},"
              f" {hist['time']:.1f} s")
    return nnx.merge(graphdef, best_params, rest), hist

4. Reservoir computing and the echo state network

The MLP sees a fixed window of \(L\) values, just like AR and NVAR. A system with an internal state can carry the history in that state instead. Reservoir computing takes a fixed nonlinear dynamical system, the reservoir, drives it with the input and trains only a linear readout of its state. Any physical system with three properties can serve as a reservoir. It must respond nonlinearly to the input, it must have fading memory, so that the state depends on the recent input and forgets the distant past, and it must offer many variables that can be read out. Nakajima et al. used a soft silicone arm, about 45 cm long and moving underwater, whose base angle was the input and whose 10 bend sensors along the arm were the state [Nakajima, Hauser, Li and Pfeifer, Sci. Rep. 5, 10487 (2015), doi:10.1038/srep10487]. The water drag supplies the nonlinearity and the damped relaxation of the arm the fading memory, and a weighted sum of the sensor signals was trained for several tasks at once.

The echo state network is the computer version of this idea [Jaeger, GMD Report 148 (2001); Lukoševičius and Jaeger, Comput. Sci. Rev. 3, 127 (2009), doi:10.1016/j.cosrev.2009.03.005]. Its state \(\mathbf r_k\in\mathbb R^{N}\) follows the leaky update \[\mathbf r_k=(1-\alpha)\,\mathbf r_{k-1}+\alpha\tanh\!\big(W\mathbf r_{k-1}+\mathbf w_{\rm in}s_k\big),\] with a sparse random matrix \(W\) (10% nonzero Gaussian entries) rescaled to the spectral radius \(\rho=\max_i|\lambda_i(W)|\), a random input vector \(\mathbf w_{\rm in}\) with entries uniform in \([-\sigma_{\rm in},\sigma_{\rm in}]\), and the leak rate \(\alpha\in(0,1]\). Neither \(W\) nor \(\mathbf w_{\rm in}\) is trained. The readout \(\tilde{\mathbf y}_k=W_{\rm out}^\top\mathbf r_k+\mathbf b\) is a ridge regression, the same as for AR and NVAR. The ESN is a recurrent network whose recurrence is random and fixed, and the training problem is convex.

def esn_base(N, seed, density=0.1):
    # random sparse W rescaled to spectral radius 1 and input vector uniform in [-1, 1]; scaled later by rho, sigma_in
    rng = np.random.default_rng(seed)
    W = rng.normal(size=(N, N)) * (rng.random((N, N)) < density)
    W /= np.max(np.abs(np.linalg.eigvals(W)))
    return W, rng.uniform(-1.0, 1.0, size=N)

@jax.jit
def esn_states(W, w_in, u, alpha, x0):
    # r_k = (1 - alpha) r_{k-1} + alpha tanh(W r_{k-1} + w_in u_k), returns all states (T, N)
    def step(x, uk):
        x = (1.0 - alpha) * x + alpha * jnp.tanh(W @ x + w_in * uk)
        return x, x
    _, X = jax.lax.scan(step, x0, u)
    return X

Echo state property

A single linear readout can only work if the state is a function of the input history alone and does not depend on the arbitrary initial state \(\mathbf r_0\). This is the echo state property. We test it directly. One reservoir with \(N=100\) units is started from two random initial states and driven by the same input, the rescaled Santa Fe signal, with \(\alpha=1\) and \(\sigma_{\rm in}=0.5\). We plot the distance \(\|\mathbf r_k-\mathbf r'_k\|\) between the two copies for several spectral radii, and once for \(\rho=1.2\) with the input switched off. The update is a contraction, and the property is guaranteed, when the largest singular value of \(W\) is below 1 [Jaeger, GMD Report 148 (2001)]. The spectral radius is the usual practical control parameter.

Code 
def esp_distance(rho, sigma_in, u, seed=1, N=100):
    # distance between two copies of one reservoir started from different random states, same input u
    W, w = esn_base(N, seed=0)

    Xb = esn_states(rho * W, sigma_in * w, u, 1.0, xb)
    return np.linalg.norm(np.asarray(Xa - Xb), axis=1)

Linear memory capacity

How much of its input history a reservoir stores is measured with a task whose input cannot be predicted from itself. The input \(u_k\) is drawn independently and uniformly from \([-1,1]\), and for every delay \(d\) a separate linear readout of \(\mathbf r_k\) is trained to return \(u_{k-d}\). Its score on test data is \(C(d)=r^2(\tilde u_{k-d},u_{k-d})\), and the linear memory capacity is \[\mathrm{MC}=\sum_{d\ge1}C(d)\le N,\] bounded by the number of linearly independent state variables [Jaeger, GMD Report 148 (2001); Dambre et al., Sci. Rep. 2, 514 (2012), doi:10.1038/srep00514]. We use \(N=50\), \(\alpha=1\), a small input scaling \(\sigma_{\rm in}=0.1\), so that the units work close to their linear range, delays \(d=1,\dots,100\), 5000 training steps and 2000 test steps after 200 discarded steps.

Code 
def memory_capacity(rho, N=50, sigma_in=0.1, d_max=100, n_wash=200, n_train=5000, n_test=2000, seed=0, beta=1e-10):
    W, w = esn_base(N, seed=seed)
    u = np.random.default_rng(100 + seed).uniform(-1, 1, n_wash + n_train + n_test)
    X = np.asarray(esn_states(rho * W, sigma_in * w, u, 1.0, jnp.zeros(N)))
    k_tr = np.arange(n_wash, n_wash + n_train); k_te = np.arange(n_wash + n_train, len(u))
    D = np.arange(1, d_max + 1)
    W_out, b = ridge_fit(X[k_tr], u[k_tr[:, None] - D[None, :]], beta)        # one column per delay d
    pred = np.asarray(X[k_te] @ W_out + b)
    return np.array([np.corrcoef(pred[:, j], u[k_te - d])[0, 1] ** 2 for j, d in enumerate(D)])

NARMA benchmark

A useful reservoir needs nonlinearity as well as memory. The nonlinear autoregressive moving-average task of order \(n\) (NARMA-\(n\)) asks for memory and nonlinearity together [Atiya and Parlos, IEEE Trans. Neural Netw. 11, 697 (2000), doi:10.1109/72.846741]. An input \(u_k\) uniform in \([0,0.5]\) drives the system \[y_k=0.3\,y_{k-1}+0.05\,y_{k-1}\sum_{i=1}^{n}y_{k-i}+1.5\,u_{k-n}u_{k-1}+0.1 ,\] and the model, which sees only \(u\), must return \(y_{k+1}\) at time \(k\). The product \(u_{k-n}u_{k-1}\) needs a memory of \(n\) steps and a multiplication, and the feedback through \(y\) adds a dependence on older inputs. Nakajima et al. trained the soft arm on NARMA-2 to NARMA-20 and report that a linear fit on the raw input fails from NARMA-5 on. We compare three models trained on the same data. The first is a linear readout of the last 20 inputs, the second a quadratic readout (NVAR) of the last 12 inputs, and the third an ESN with \(N=100\) units whose \(\rho\), \(\sigma_{\rm in}\) and ridge strength are chosen on validation data. The score is the NMSE on 1000 test steps after 2500 fitting and 500 validation steps.

ReservoirPy contains a NARMA generator, reservoirpy.datasets.narma. Its loop computes \(y_{t+1}=a_1y_t+a_2y_t\sum_{j=t-n}^{t-1}y_j+b\,u_{t-n}u_t+c\), so with \(k=t+1\) its sum runs over \(y_{k-2},\dots,y_{k-n-1}\) and its product is \(u_{k-n-1}u_{k-1}\), shifted by one step from the formula above. Our generator takes the first lag of the sum and the lag of the product as arguments, and with the shifted values it reproduces the library series.

Code 
@partial(jax.jit, static_argnums=(1, 2, 3))
def narma(u, n, i0=1, m=None):
    # y_k = 0.3 y_{k-1} + 0.05 y_{k-1} sum_{i=i0}^{i0+n-1} y_{k-i} + 1.5 u_{k-m} u_{k-1} + 0.1, y = 0 before k = n+1
    m = n if m is None else m
    def body(k, y):
        window = jax.lax.dynamic_slice(y, (k - i0 - n + 1,), (n,))      # y_{k-i0-n+1}, ..., y_{k-i0}
        return y.at[k].set(0.3 * y[k - 1] + 0.05 * y[k - 1] * window.sum() + 1.5 * u[k - m] * u[k - 1] + 0.1)
    return jax.lax.fori_loop(n + 1, u.shape[0], body, jnp.zeros_like(u))

Forecasting with the echo state network

For the forecasting task the reservoir has \(N=300\) units and is driven by the rescaled signal from the first sample on. Its state at a forecast origin \(k\) has therefore seen at least 64 values, and the readout maps \(\mathbf r_k\) to all 50 leads. The spectral radius \(\rho\in\{0.5,0.8,0.95,1.1\}\), the input scaling \(\sigma_{\rm in}\in\{0.1,0.5,1\}\), the leak rate \(\alpha\in\{0.3,1\}\) and the ridge strength \(\beta\in\{10^{-8},10^{-6},10^{-4},10^{-2}\}\) are chosen by the validation \(C_{\rm tot}\). One fixed random reservoir (seed 0) is used for all signals. Fitting this model means running the reservoir once and solving one linear system for each setting.

5. Recurrent neural network

The reservoir keeps a random recurrence and trains only the readout. The recurrent neural network (RNN) trains the recurrence as well [Elman, Cogn. Sci. 14, 179 (1990), doi:10.1207/s15516709cog1402_1]. Its hidden state \(\mathbf h_k\in\mathbb R^{n_h}\) is updated by \[\mathbf h_k=\tanh\!\big(W_h\mathbf h_{k-1}+W_x s_k+\mathbf b\big),\qquad \tilde{\mathbf y}_k=W_y\mathbf h_k+\mathbf b_y ,\] with \(W_h\in\mathbb R^{n_h\times n_h}\), \(W_x\in\mathbb R^{n_h\times1}\) and the readout \(W_y\in\mathbb R^{50\times n_h}\). With \(\alpha=1\) this is the ESN update, and all weights are now learned. We start every forecast from \(\mathbf h=0\) at the beginning of the window, feed the \(L=64\) values of \(\mathbf v_k\) one after the other, and read the 50 leads from the last state. Drawn for every time step, the network becomes a deep feed-forward network with one layer per input value and the same weights in every layer, the unrolled network below.

Backpropagation through time

Gradient descent needs the derivative of the loss with respect to \(W_h\), which enters every step. Applying the chain rule to the unrolled network gives backpropagation through time (BPTT). The loss depends on the last state \(\mathbf h_k\), and a change of an earlier state \(\mathbf h_j\) reaches \(\mathbf h_k\) through the product of step Jacobians \[\frac{\partial\mathbf h_k}{\partial\mathbf h_j}=\prod_{i=j+1}^{k}D_iW_h,\qquad D_i=\mathrm{diag}\big(1-\mathbf h_i^2\big),\] where \(D_i\) contains the derivatives \(\tanh'=1-\tanh^2\in(0,1]\). The contribution of an input \(m\) steps in the past to the gradient is multiplied by \(m\) such factors. If the factors shrink vectors, the product decays exponentially and the network cannot learn from distant inputs. This is the vanishing gradient problem [Bengio, Simard and Frasconi, IEEE Trans. Neural Netw. 5, 157 (1994), doi:10.1109/72.279181; Hochreiter and Schmidhuber, Neural Comput. 9, 1735 (1997), doi:10.1162/neco.1997.]. If the factors stretch vectors, the product grows exponentially and gradients explode [Pascanu, Mikolov and Bengio, ICML (2013), arXiv:1211.5063]. Clipping the gradient norm, as in our training loop, limits the damage of exploding gradients and does nothing against vanishing ones.

We measure the norm \(\|\partial\mathbf h_k/\partial\mathbf h_0\|_2\) (largest singular value) for random RNNs with \(n_h=64\) driven by the Santa Fe signal. The recurrent matrix \(W_h\) has Gaussian entries rescaled to the spectral radius \(\rho\in\{0.5,1.0,1.5\}\) and \(W_x\) has entries uniform in \([-1,1]\). For each \(\rho\) we average \(\log_{10}\) of the norm over 10 random networks. The Jacobian product is accumulated along the trajectory, and for one network we check it against jax.jacfwd of the map \(\mathbf h_0\mapsto\mathbf h_k\).

def rnn_jacobian_norms(W_h, w_x, u, h0):
    # accumulate J_k = D_k W_h J_{k-1} along the driven trajectory; returns ||J_k||_2 for k = 1..len(u)
    n = W_h.shape[0]
    def step(carry, uk):
        h, J = carry
        h = jnp.tanh(W_h @ h + w_x * uk)
        J = (1.0 - h ** 2)[:, None] * (W_h @ J)
        return (h, J), jnp.linalg.norm(J, 2)
    _, norms = jax.lax.scan(step, (h0, jnp.eye(n)), u)
    return norms

def rnn_map(h0, W_h, w_x, u):
    # h_0 -> h_k for the inputs u
    return jax.lax.scan(lambda h, uk: (jnp.tanh(W_h @ h + w_x * uk), None), h0, u)[0]

The Jacobian product is the tangent propagator of the hidden-state dynamics driven by the input, the object from which Lyapunov exponents are computed in Lecture 7, and the measured rate is a finite-time estimate of the largest Lyapunov exponent of this driven dynamics. Read as an analogy, vanishing gradients correspond to a contracting hidden dynamics with a negative exponent, exploding gradients to an expanding one with a positive exponent, and a network that should learn long dependencies has to sit close to the boundary between them.

6. Gated cells, LSTM and GRU

Long short-term memory

The LSTM [Hochreiter and Schmidhuber, Neural Comput. 9, 1735 (1997), doi:10.1162/neco.1997.] adds a cell state \(\mathbf c_k\) to the hidden state and controls it with three gates whose values lie in \((0,1)\). With the sigmoid \(\sigma(a)=1/(1+e^{-a})\), the elementwise product \(\odot\) and the concatenation \([\mathbf h_{k-1},s_k]\), \[ \begin{aligned} \mathbf f_k&=\sigma\big(W_f[\mathbf h_{k-1},s_k]+\mathbf b_f\big) &&\text{forget gate}\\ \mathbf i_k&=\sigma\big(W_i[\mathbf h_{k-1},s_k]+\mathbf b_i\big) &&\text{input gate}\\ \mathbf g_k&=\tanh\big(W_g[\mathbf h_{k-1},s_k]+\mathbf b_g\big) &&\text{candidate}\\ \mathbf o_k&=\sigma\big(W_o[\mathbf h_{k-1},s_k]+\mathbf b_o\big) &&\text{output gate}\\ \mathbf c_k&=\mathbf f_k\odot\mathbf c_{k-1}+\mathbf i_k\odot\mathbf g_k\\ \mathbf h_k&=\mathbf o_k\odot\tanh(\mathbf c_k). \end{aligned} \] The forget gate decides how much of the cell state is kept, the input gate how much of the candidate is written, and the output gate how much of the cell is shown in \(\mathbf h_k\). The cell state is updated by an elementwise product and a sum, with no matrix and no squashing function on the way from \(\mathbf c_{k-1}\) to \(\mathbf c_k\). Along this direct path the Jacobian is diagonal, \[\left.\frac{\partial\mathbf c_k}{\partial\mathbf c_j}\right|_{\rm direct}=\prod_{i=j+1}^{k}\mathrm{diag}(\mathbf f_i).\] In the original LSTM the cell had a self-connection of weight 1, so this factor was the identity, the constant error carousel through which errors flow back without decay. The forget gate, added by Gers, Schmidhuber and Cummins, makes the factor learnable [Neural Comput. 12, 2451 (2000), doi:10.1162/089976600300015015]. A unit with a constant forget value \(f\) keeps a fraction \(f^m=e^{-m/\tau_{\rm mem}}\) of its content after \(m\) steps, a memory time \[\tau_{\rm mem}=-\frac{1}{\ln f}.\] For \(f=0.9\) this is 9.5 steps and for \(f=0.99\) it is 99.5 steps. Gers et al. recommend a positive initial forget bias so that the cell starts by keeping information. We initialise \(\mathbf b_f=1\), which gives \(f=\sigma(1)=0.73\) and \(\tau_{\rm mem}=3.2\) steps at the start of training, and let the training lengthen it where the data require.

Gated recurrent unit

The GRU [Cho et al., EMNLP (2014), doi:10.3115/v1/D14-1179] merges the cell and hidden states and uses two gates. We write it in the convention of Cho et al. and of the libraries (flax.nnx.GRUCell, PyTorch), where the update gate \(\mathbf z_k\) multiplies the old state, \[ \begin{aligned} \mathbf r_k&=\sigma\big(W_{ir}s_k+\mathbf b_{ir}+W_{hr}\mathbf h_{k-1}\big) &&\text{reset gate}\\ \mathbf z_k&=\sigma\big(W_{iz}s_k+\mathbf b_{iz}+W_{hz}\mathbf h_{k-1}\big) &&\text{update gate}\\ \mathbf n_k&=\tanh\big(W_{in}s_k+\mathbf b_{in}+\mathbf r_k\odot(W_{hn}\mathbf h_{k-1})\big) &&\text{candidate}\\ \mathbf h_k&=(1-\mathbf z_k)\odot\mathbf n_k+\mathbf z_k\odot\mathbf h_{k-1}. \end{aligned} \] Other texts use the complementary convention, in which \(\mathbf z_k\) multiplies the candidate. The two are related by \(\mathbf z\to1-\mathbf z\). With \(z_k\to1\) a unit keeps its old value, and along this path \(\partial\mathbf h_k/\partial\mathbf h_{k-1}|_{\rm direct}=\mathrm{diag}(\mathbf z_k)\), the analogue of the LSTM forget gate. The reset gate \(\mathbf r_k\) decides how much of the old state enters the candidate. In the libraries it multiplies \(W_{hn}\mathbf h_{k-1}\), while the paper of Cho et al. applies it before the matrix, \(W_{hn}(\mathbf r_k\odot\mathbf h_{k-1})\). We use the library form so that our cell can be checked against nnx.GRUCell.

Parameter counts

For an input of dimension \(n_x\) every gate or candidate of the LSTM has a matrix acting on \([\mathbf h_{k-1},s_k]\) and a bias, \(n_h^2+n_hn_x+n_h\) parameters, and there are four of them. The GRU has three such blocks and the vanilla RNN one, \[P_{\rm LSTM}=4(n_h^2+n_hn_x+n_h),\qquad P_{\rm GRU}=3(n_h^2+n_hn_x+n_h),\qquad P_{\rm RNN}=n_h^2+n_hn_x+n_h,\] plus \(50(n_h+1)\) for the readout to 50 leads. We use \(n_h=32\) and \(n_x=1\), and the counts are checked against the implemented modules in the next section.

7. Recurrent cells in flax.nnx

We implement the three cells as nnx.Module classes with one method, cell(carry, s_k) -> (carry, h_k), the signature of the library cells. The carry is \(\mathbf h\) for the RNN and the GRU and the pair \((\mathbf c,\mathbf h)\) for the LSTM. A cell acts on a batch, so \(s_k\) has shape \((B,1)\) and \(\mathbf h\) shape \((B,n_h)\). A separate module Recurrent runs any cell over the window with jax.lax.scan, which compiles the loop over the \(L\) time steps once, and applies the linear readout to the last hidden state. The input window has shape \((B,L,1)\), and scan iterates over the leading axis, so we swap the batch and time axes before the loop.

The initialisation follows the libraries. Input matrices use the LeCun normal distribution, recurrent matrices of the RNN and the GRU a random orthogonal matrix, whose singular values are all 1, so that the initial Jacobian product neither shrinks nor grows through \(W_h\), and the LSTM gets the forget bias \(\mathbf b_f=1\).

orthogonal = nnx.initializers.orthogonal()

class RNNCell(nnx.Module):
    # h_k = tanh(W_x s_k + b + W_h h_{k-1})
    def __init__(self, n_x, n_h, *, rngs):
        self.n_h = n_h
        self.Wx = nnx.Linear(n_x, n_h, rngs=rngs)                                   # W_x and b
        self.Wh = nnx.Linear(n_h, n_h, use_bias=False, kernel_init=orthogonal, rngs=rngs)
    def init_carry(self, B, dtype):
        return jnp.zeros((B, self.n_h), dtype)
    def __call__(self, h, s):
        h = jnp.tanh(self.Wx(s) + self.Wh(h))
        return h, h

class GRUCell(nnx.Module):
    # library convention: h_k = (1 - z) * n + z * h_{k-1}, reset gate applied after W_hn
    def __init__(self, n_x, n_h, *, rngs):
        self.n_h = n_h
        self.Wi = nnx.Linear(n_x, 3 * n_h, rngs=rngs)                               # [W_ir, W_iz, W_in] and biases
        self.Wh = nnx.Linear(n_h, 3 * n_h, use_bias=False, kernel_init=orthogonal, rngs=rngs)   # [W_hr, W_hz, W_hn]
    def init_carry(self, B, dtype):
        return jnp.zeros((B, self.n_h), dtype)
    def __call__(self, h, s):
        xr, xz, xn = jnp.split(self.Wi(s), 3, axis=-1)
        hr, hz, hn = jnp.split(self.Wh(h), 3, axis=-1)
        r = jax.nn.sigmoid(xr + hr)                     # reset gate
        z = jax.nn.sigmoid(xz + hz)                     # update gate
        n = jnp.tanh(xn + r * hn)                       # candidate
        h = (1.0 - z) * n + z * h
        return h, h

class LSTMCell(nnx.Module):
    # one matrix on the concatenation [h_{k-1}, s_k] for the four blocks (i, f, g, o)
    def __init__(self, n_x, n_h, *, rngs, forget_bias=1.0):
        self.n_h = n_h
        self.W = nnx.Linear(n_h + n_x, 4 * n_h, rngs=rngs)
        self.W.bias[...] = self.W.bias[...].at[n_h:2 * n_h].set(forget_bias)      # b_f = 1 (Gers et al. 2000)
    def init_carry(self, B, dtype):
        return (jnp.zeros((B, self.n_h), dtype), jnp.zeros((B, self.n_h), dtype))
    def gates(self, carry, s):
        c, h = carry
        a_i, a_f, a_g, a_o = jnp.split(self.W(jnp.concatenate([h, s], axis=-1)), 4, axis=-1)
        return jax.nn.sigmoid(a_i), jax.nn.sigmoid(a_f), jnp.tanh(a_g), jax.nn.sigmoid(a_o)
    def __call__(self, carry, s):
        c, h = carry
        i, f, g, o = self.gates(carry, s)
        c = f * c + i * g                               # cell state: elementwise only
        h = o * jnp.tanh(c)
        return (c, h), h

class Recurrent(nnx.Module):
    # any cell run over the window, linear readout of the last hidden state to the 50 leads
    def __init__(self, cell, n_h, n_out, *, rngs):
        self.cell = cell
        self.head = nnx.Linear(n_h, n_out, rngs=rngs)    # W_y, b_y
    def hidden_states(self, V):
        # V: (B, L, 1) -> all hidden states (L, B, n_h)
        carry = self.cell.init_carry(V.shape[0], V.dtype)
        _, hs = jax.lax.scan(lambda c, s: self.cell(c, s), carry, jnp.swapaxes(V, 0, 1))
        return hs
    def __call__(self, V):
        return self.head(self.hidden_states(V)[-1])

Memory times of the trained LSTM

The forget gates of the trained LSTM tell which memory times it uses. For every unit we average \(f\) over all steps of the test windows and convert the mean to \(\tau_{\rm mem}=-1/\ln\bar f\).

Code 
def lstm_forget_values(model, V):
    # forget-gate values f_k of all units along the windows V: (L, B, n_h)
    cell = model.cell
    def step(carry, s):
        i, f, g, o = cell.gates(carry, s)
        c = f * carry[0] + i * g
        return (c, o * jnp.tanh(c)), f
    return jax.lax.scan(step, cell.init_carry(V.shape[0], V.dtype), jnp.swapaxes(V, 0, 1))[1]

The comparison follows the characterisation of the signals in Lecture 7. The limit cycle of Mackey–Glass at \(\tau_{\rm MG}=15\) is predictable by every model with a window of past values. The linear AR model reaches \(C_{\rm tot}=49.8\) and all nonlinear models 50.0, while persistence oscillates with the period of the cycle. A periodic signal needs no nonlinear features.

The chaotic Mackey–Glass signals separate linear from nonlinear models. AR reaches 33.1 at \(\tau_{\rm MG}=25\) and 38.0 at \(\tau_{\rm MG}=35\). NVAR raises this to 45.5 and 48.6, and the ESN and all trained networks reach between 48.3 and 49.9, with \(C(50)\) between 0.88 and 0.997. The delay equation has a one-dimensional input and a smooth nonlinearity, and a window that covers the delay already contains what the forecast needs, so the ESN and the trained networks differ by less than two units here.

The Lorenz signal separates the models with a fixed window from those with a learned state. AR and NVAR give the same value, 15.4, with \(\tau_{1/2}=16\). The flow is symmetric under \((x,y,z)\to(-x,-y,z)\), so the future of the first coordinate is an odd function of its past. Quadratic monomials are even under this symmetry, which is consistent with NVAR giving no gain (the rescaling to \([0,1]\) shifts the centre of the symmetry approximately to 0.5, and the linear terms and the intercept absorb this shift). The ESN reaches 39.2, the MLP 29.4, and the RNN, GRU and LSTM 43.8, 45.1 and 43.8 with \(C(\tau)>0.5\) up to the last lead, which corresponds to one time unit of the Lorenz flow. The odd nonlinear functions that the forecast needs are available to tanh networks and reservoirs, and the recurrent networks learn them best among the models tested.

The Santa Fe laser, whose large pulses fold the reconstructed attractor, gives the clearest ranking. AR reaches 16.5, NVAR 34.7, ESN 34.7, MLP 35.3, and the recurrent networks 42.5 (RNN), 43.0 (GRU) and 44.3 (LSTM). All of these models except the ESN see the same 64 past values, and the trained LSTM uses memory times of a few steps. The advantage of the recurrent networks here therefore comes from the nonlinear processing of the recent window, which the recurrence learns better than a fixed list of monomials, a fixed random reservoir, or a single tanh layer of 64 units. The validation search chose \(\rho=1.1\) for the ESN on Lorenz and on Mackey–Glass at \(\tau_{\rm MG}=15\). It does not test the echo state property, which our direct test above found violated at \(\rho=1.2\) for the Santa Fe input, so these two ESN results come from reservoirs whose dependence on the initial state was not checked. These statements hold for one fixed-size setting of each model, chosen without a separate search for each signal, and with one seed for all signals but Santa Fe.

Ridge regression solves one linear system, while backpropagation through time runs every training window forward and backward through all \(L\) steps of the recurrence, for several hundred epochs. The whole ESN search over 24 reservoirs and 4 ridge strengths took 56 s for all five signals, less than the training of two gated networks. For the Mackey–Glass signals the ESN comes within two units of \(C_{\rm tot}\) of the best network, and the extra cost pays off on Santa Fe and Lorenz.

10. Free run and exposure bias

All models above were trained and tested with the true past as input. During training a recurrent network is always fed measured values, which is called teacher forcing. A model that generates a signal must instead feed its own predictions back as inputs. Its errors then enter the input, a situation it has never seen in training, and they can grow. This mismatch between training and use is called exposure bias.

We test it on the Santa Fe laser. Every model predicts one step ahead with its \(\tau=1\) output, the prediction is appended to the window (for the ESN it drives the reservoir), and the procedure is repeated for 200 steps from the origin \(k_0=2999\), the last sample of the training block. We measure the error of the free run by the NMSE over the first 50 and 200 steps and by the number of steps before the error \(|\tilde s_{k_0+j}-s_{k_0+j}|\) first exceeds 0.2, a fifth of the training range.

def free_run_window(one_step, s, k0, n_steps, L):
    # one_step(window of the last L values) -> next value; the prediction is appended to the window
    buf = list(s[k0 - L + 1:k0 + 1])
    out = []

        y = float(np.clip(y, -10, 10))              # keeps a diverging model finite
        out.append(y); buf.append(y)

def esn_free_run(e, s, k0, n_steps):
    # state at k0 from the true inputs, then the tau = 1 output drives the reservoir

        return x, y

The free run separates the models differently from the direct forecasts. The linear AR model relaxes within about 50 steps to a small regular oscillation around the mean, the behaviour of a stable linear system. NVAR and the ESN follow the pulses for some 40 to 60 steps and then diverge, because their feedback loop through the quadratic features or the reservoir is unstable (the crosses mark where the curves leave the plotted range). The MLP keeps oscillating but with distorted pulses, and its error exceeds 0.2 after 9 steps. The LSTM stays close to the data for 110 steps, with NMSE 0.007 over the first 50 steps, and then keeps pulsating with a smaller amplitude and a drifting phase. The RNN and the GRU leave the data after 23 and 38 steps, the GRU settling to a small oscillation. Over 200 steps no model reproduces the data, and the NMSE values are around 1 or larger, the level of a forecast that has lost the phase.

The networks were trained only on true past values, with teacher forcing. A model that is good at one-step prediction need not produce a good free run, because its own errors move the input away from the data it was trained on. These results come from one origin and one seed. Free runs of chaotic signals amplify small differences between models, so the ranking of the free runs is far less robust than the ranking of the direct forecasts. Training on the model’s own predictions, or on noisy inputs, is the usual remedy for this exposure bias.

Summary

We compared models of increasing flexibility on five signals with one protocol, direct forecasts of the leads \(\tau=1,\dots,50\) from a window of \(L=64\) past values, scored by the capacity \(C(\tau)=r^2\) and its sum \(C_{\rm tot}\). Linear AR suffices for the limit cycle of Mackey–Glass at \(\tau_{\rm MG}=15\). The chaotic signals need nonlinear features, and the folding pulses of the Santa Fe laser show the largest differences between models.

An MLP on the window learns its features instead of using the fixed monomials of NVAR. The echo state network keeps the history in a fixed random dynamical system and trains only a ridge readout. It forgets its initial state when the spectral radius is small enough, which we tested directly, it has a linear memory capacity of up to 20 for 50 units, and it solves the NARMA-2 and NARMA-5 tasks where a linear readout of the inputs fails. The reservoir idea carries over to physical systems such as the soft arm of Nakajima et al.

The recurrent neural network trains the recurrence itself. Backpropagation through time multiplies the step Jacobians \(D_iW_h\), so gradients vanish for a contracting hidden dynamics and explode for an expanding one, which we measured for random networks. The LSTM and the GRU add gated paths whose direct Jacobians are diagonal products of gate values, so the gates act as learned memory times \(-1/\ln f\). We implemented all three cells in flax.nnx, checked them against the library cells to round-off precision, and trained them with Adam, gradient clipping and early stopping on rescaled windows. On Santa Fe the order LSTM > GRU > RNN > MLP is stable over three seeds, and the recurrent networks also lead on Lorenz, at a training cost several hundred times that of the reservoir. In free runs on their own predictions all models lose the phase within a few pulsation periods, and the direct forecasts with teacher forcing overestimate how well a model generates the signal.
