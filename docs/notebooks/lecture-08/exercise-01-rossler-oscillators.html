Exercise 01 — Rössler system and superimposed oscillators

The time-series labs characterised three signals and forecast them with linear models, NVAR (nonlinear vector autoregression) and recurrent neural networks. In this exercise we apply the same toolbox to two new signals taken from reservoirpy.datasets, and we analyse each of them before we forecast it, as in the labs.

The first signal is a sum of eight sine waves with incommensurate frequencies, the multiple superimposed oscillator (MSO) benchmark of reservoir computing. Its motion is quasi-periodic, with a finite number of oscillation modes. We locate its spectral lines, show that an autoregressive (AR) model of order \(2K\) for \(K\) sinusoids forecasts it almost perfectly, and explain this with the Koopman picture of Lab 035. The second signal is the \(x\) coordinate of the Rössler system, a three-dimensional chaotic flow with a single nonlinear term. We study its physics, spectrum, autocorrelation function (ACF), delay embedding, Lyapunov spectrum and Kaplan–Yorke dimension \(D_{\rm KY}\). In Section 3 we forecast both signals with persistence, AR, the moving-average (MA) model, NVAR, a recurrent neural network (RNN) and a long short-term memory (LSTM) network, and read the results against the leading Lyapunov exponent \(\lambda_1\) and \(D_{\rm KY}\).

Each exercise states what to compute and what to report, and names the lab whose functions and conventions it reuses. The protocol and the scores are those of Lab 036 and are defined in the first code cell, with one change. The rescaling to \([0,1]\) uses the minimum and maximum of the fitting block, the first 2500 samples, and every diagnostic that could inform a forecasting model, the delay embedding in particular, is computed on the fitting block only, so that neither the validation block nor the test block influences any choice. Two exercises are marked as optional. The surrogate test of both signals closes the analysis part, and an echo state network (ESN) closes the forecasting part. No other exercise uses their results.

def rescale01(s, n_fit=N_FIT):
    lo, hi = s[:n_fit].min(), s[:n_fit].max()
    return (s - lo) / (hi - lo)

def windows(s, ks, L=L_WIN):
    # inputs U[i] = (s_{k-L+1}, ..., s_k) and targets Y[i] = (s_{k+1}, ..., s_{k+50}) for k = ks[i]
    U = s[ks[:, None] + np.arange(-L + 1, 1)[None, :]]
    Y = s[ks[:, None] + TAUS[None, :]]
    return U, Y

@jax.jit
def nmse_and_r(pred, true):
    # pred, true: (n, TAU_MAX); averages over the n origins, one value per lead
    err = jnp.mean((pred - true) ** 2, axis=0) / jnp.var(true, axis=0)
    pc, tc = pred - pred.mean(0), true - true.mean(0)
    r = jnp.sum(pc * tc, 0) / jnp.sqrt(jnp.sum(pc ** 2, 0) * jnp.sum(tc ** 2, 0))
    return err, r

def score(pred, true):
    # NMSE(tau), r(tau), C(tau) = r^2, C_tot = sum_tau C(tau) and the skill horizon tau_1/2 (first tau with C < 0.5)
    e, r = (np.asarray(a) for a in nmse_and_r(jnp.asarray(pred, jnp.float64), jnp.asarray(true, jnp.float64)))
    C = r ** 2
    below = np.nonzero(C < 0.5)[0]
    return dict(nmse=e, r=r, C=C, Ctot=float(C.sum()), tau_half=int(below[0] + 1) if len(below) else None)

1. Multiple superimposed oscillators

The MSO signal is a sum of \(K\) sine waves sampled at integer times \(n=0,1,\dots,N-1\), \[ s_n=\sum_{i=1}^{K}\sin(\omega_i n), \] where \(\omega_i\) are angular frequencies in radians per sample. The cyclic frequency of the \(i\)-th wave is \(f_i=\omega_i/2\pi\) in cycles per sample. Jaeger introduced the two-frequency version as a benchmark that a standard echo state network fails to continue in free run [H. Jaeger, M. Lukoševičius, D. Popovici and U. Siewert, Neural Netw. 20, 335 (2007), doi:10.1016/j.neunet.2007.04.016], and Roeschies and Igel extended it to eight frequencies [B. Roeschies and C. Igel, Logic J. IGPL 18, 635 (2010), doi:10.1093/jigpal/jzp043]. ReservoirPy provides the generator mso(n_timesteps, freqs, normalize=True) and the two presets mso2 with \(\omega=(0.2,0.311)\) and mso8 with \[ \boldsymbol\omega=(0.2,\ 0.311,\ 0.42,\ 0.51,\ 0.63,\ 0.74,\ 0.85,\ 0.97). \] With normalize=True the library rescales the whole record to \([-1,1]\) with its own minimum and maximum, which uses the test block. We therefore generate the signal with normalize=False and apply the protocol rescaling to \([0,1]\) fitted on the fitting block.

Exercise 1.4. Autoregressive model and Koopman eigenvalues

A single sine wave obeys an exact linear recursion. From \(\sin(\omega(n+1))+\sin(\omega(n-1))=2\cos\omega\,\sin(\omega n)\), \[ s_{n+1}=2\cos\omega\;s_n-s_{n-1}, \] an AR(2) model without noise whose characteristic roots are \(e^{\pm i\omega}\). A sum of \(K\) sine waves with distinct frequencies obeys the AR(\(2K\)) recursion whose characteristic polynomial is the product of the \(K\) factors \(1-2\cos\omega_i\,z+z^2\). In the language of Lab 035, each wave is spanned by a pair of Koopman eigenfunctions with eigenvalues \(e^{\pm i\omega_i}\), the delay vector of length \(2K\) is a dictionary that is invariant under the dynamics, and the AR coefficients form the last row of its companion matrix.

Verify this numerically. 2. Rössler system

Rössler looked for the simplest autonomous flow with chaotic motion and found a system with three variables and a single nonlinear term [O. E. Rössler, Phys. Lett. A 57, 397 (1976), doi:10.1016/0375-9601(76)90101-8], \[ \dot x=-y-z,\qquad \dot y=x+a\,y,\qquad \dot z=b+z\,(x-c). \] The linear part in the \((x,y)\) plane is an oscillator with negative damping for \(a>0\), so trajectories near the plane spiral outwards. The variable \(z\) stays small until \(x\) exceeds \(c\). Then the product \(zx\) makes \(z\) grow quickly, and the term \(-z\) in \(\dot x\) throws the trajectory back towards the centre of the spiral, where the outward motion starts again. The stretching happens on the spiral and the folding in the excursion in \(z\), the same two ingredients as in the logistic map of Lab 033. We use the standard parameters \(a=0.2\), \(b=0.2\), \(c=5.7\), which are the defaults of ReservoirPy, and we observe only \(x(t)\).

3. Forecasts

We forecast both signals with the protocol of Lab 036. The fitting origins are \(k=63,\dots,2449\), the validation origins \(k=2499,\dots,2949\) and the test origins \(k=2999,\dots,3949\), and every model returns the leads \(\tau=1,\dots,50\) at once, one output per lead. The forecast from the origin \(k\) uses only the values \(s_0,\dots,s_k\), and the input window is at most the last \(L=64\) of them, \((s_{k-63},\dots,s_k)\). The targets \(s_{k+1},\dots,s_{k+50}\) of the fitting origins end at sample 2499, before the validation block, and those of the validation origins end at sample 2999, before the test block, so no input window or target used for fitting or for a choice reaches the test block. The first code cell checks these conditions.

Persistence, AR and NVAR read the window and nothing else. Persistence repeats the last value, and AR and NVAR are ridge regressions of the 50 targets on the delay vector \((s_k,\dots,s_{k-p+1})\) and on the delay vector with its quadratic monomials. The NVAR features are fixed, and only the linear readout is fitted. The MA model forecasts from its last \(q=8\) one-step prediction errors \(e_k,\dots,e_{k-7}\), which the fitted filter computes from all values up to the origin. The RNN and the LSTM network start from a zero hidden state at the oldest value of the window and carry their state through the 64 values, so they are also functions of the window. All their weights, the recurrence and the linear readout of the last hidden state, are learned by gradient descent. The optional ESN keeps a state driven by the signal from the first sample, with a fixed random recurrence and a ridge readout. For the MSO signal, persistence and the direct AR model were computed in Exercise 1.5.

The capacity \(C(\tau)=r(\tau)^2\) is biased upwards on a finite test block. For \(n\) test origins and a forecast unrelated to the targets, \(r(\tau)\) scatters around zero with variance close to \(1/(n-1)\), so \(C(\tau)\approx1/(n-1)=0.0011\) for \(n=951\) and \(C_{\rm tot}\approx0.05\). A total of this size means no skill.
