Lab 033 — Signal characterisation

A time series \(s_1,s_2,\dots,s_N\) is a sequence of measurements of one quantity taken at equal time intervals \(\Delta t\). Before we try to forecast such a series with any model, linear or neural, we characterise the signal itself. We ask how long it remembers its past, which frequencies carry its power, how many past values are needed to fix the present state of the system that produced it, how fast two nearby states separate, and how many effective degrees of freedom the motion explores. The answers set what any forecasting method can achieve, and they guide the choice of the forecasting models of Lab 034 in this lecture and of Labs 035 and 036 in Lecture 8. Definitions, reference numbers and the reference implementations follow the lecture notes of M. Płodzień, Lecture Notes on Time Series Forecasting. A Dynamical-Systems Approach, with code at https://github.com/MarcinPlodzien/time-series-forecasting-book, which we call the book below.

We work with three signals that are used throughout Lectures 7 and 8. The first is the \(x\) coordinate of the Lorenz-63 model of thermal convection, a three-dimensional chaotic flow. The second is the Mackey–Glass delay equation for blood-cell production at three values of the feedback delay, which give a periodic orbit, weak chaos and developed chaos. The third is the intensity of a chaotic far-infrared laser measured in the laboratory, the Santa Fe data set A. Section 1 generates the signals. Section 2 defines the time-series tasks and compares easy, chaotic and stochastic signals. Section 3 introduces the physics and the equations of the three benchmark signals. Sections 4 and 5 treat the linear statistics, the autocorrelation function (ACF) and the power spectral density (PSD), with the standard tools of signal processing. Section 6 reconstructs the state space from a single measured coordinate (delay embedding). Section 7 introduces deterministic chaos on the simplest example, the logistic map, and Section 8 computes the Lyapunov exponents of the flows and of the measured laser data. Section 9 turns them into an attractor dimension and a prediction horizon, Section 10 collects all numbers in one table, and Section 11 states what they imply for forecasting. The optional Appendix A asks whether the signals contain structure beyond what a linear random process with the same spectrum can produce (surrogate data test).

All computations use JAX in double precision (jax_enable_x64). Where a standard library offers the same quantity (statsmodels for the ACF, scipy for periodograms, the Welch estimate and nearest-neighbour search) we compute it with both and compare.

1. Signals and protocol

The generators below are shared by all notebooks of Lectures 7 and 8, so that every model is trained and tested on the same numbers. They integrate the equations with the fourth-order Runge–Kutta method (RK4) in jax.lax.scan and return \(N=4000\) samples per signal. The last lines define the common protocol of the forecasting labs, a chronological split into a training block of 3000 samples, whose last 500 serve for validation, and a test block of the final 1000 samples, with rescaling to \([0,1]\) fitted on the training block only.

Code 
# Lorenz-63 with sigma = 10, rho = 28, beta = 8/3. RK4 with h = 0.01, one sample every 2 steps (dt = 0.02).
# Initial state (1, 1, 1); the first 2500 samples (50 time units) are discarded. We keep the x component.
def lorenz_rhs(u, sigma=10.0, rho=28.0, beta=8.0/3.0):
    x, y, z = u
    return jnp.array([sigma*(y - x), x*(rho - z) - y, x*y - beta*z])

def rk4_step(f, u, h):
    k1 = f(u); k2 = f(u + 0.5*h*k1); k3 = f(u + 0.5*h*k2); k4 = f(u + h*k3)
    return u + h/6.0*(k1 + 2*k2 + 2*k3 + k4)

@partial(jax.jit, static_argnums=(0, 1, 2))
def lorenz_trajectory(n_samples, sub=2, n_discard=2500, h=0.01):
    """Returns array (n_samples, 3) sampled every `sub` RK4 steps (dt = sub*h)."""
    def one_sample(u, _):
        u = jax.lax.fori_loop(0, sub, lambda i, v: rk4_step(lorenz_rhs, v, h), u)
        return u, u
    u0 = jnp.array([1.0, 1.0, 1.0])
    u, _ = jax.lax.scan(one_sample, u0, None, length=n_discard)
    _, traj = jax.lax.scan(one_sample, u, None, length=n_samples)
    return traj

# Mackey-Glass dx/dt = beta x(t-tau)/(1 + x(t-tau)^n) - gamma x with beta = 0.2, gamma = 0.1, n = 10.
# RK4 with h = 0.1; the delayed value at the half step is the linear interpolation of the two stored values.
# Constant history x = 1.2 on [-tau, 0]; the first 3000 fine steps are discarded and every 10th point is kept
# (unit sampling). This is the scheme of the time-series book benchmark (it reproduces its tau = 17 file).
def mackey_glass(tau, n_samples, h=0.1, x0=1.2, transient=3000, every=10,
                 beta=0.2, gamma=0.1, n=10):
    lag = int(round(tau / h))
    f = lambda x, xd: beta * xd / (1.0 + xd**n) - gamma * x
    def step(buf, _):
        # buf = (x[i-lag], ..., x[i]) is the delay window, length lag+1
        x, xd0, xd1 = buf[-1], buf[0], buf[1]
        xdh = 0.5 * (xd0 + xd1)
        k1 = f(x, xd0); k2 = f(x + 0.5*h*k1, xdh); k3 = f(x + 0.5*h*k2, xdh); k4 = f(x + h*k3, xd1)
        xn = x + h/6.0*(k1 + 2*k2 + 2*k3 + k4)
        return jnp.concatenate([buf[1:], xn[None]]), xn
    n_steps = transient + n_samples * every
    _, xs = jax.lax.scan(step, jnp.full(lag + 1, x0), None, length=n_steps)
    x = np.concatenate([np.full(lag + 1, x0), np.asarray(xs)])
    return x[transient::every][:n_samples]

2. Time-series tasks and kinds of signals

Recall and forecast

At the current step \(k\) a model has seen the values \(s_1,\dots,s_k\). Two tasks are defined by the target. In a recall task the target is a past value \(y_k=s_{k-\tau}\), which tests memory. In a forecasting task the target is a future value \(y_k=s_{k+\tau}\), and \(\tau\) is called the horizon. The figure marks both on a stretch of the Santa Fe laser record, rescaled to \([-1,1]\) for the drawing.

Signals that are easy to forecast

Some signals can be forecast exactly once their rule is recognised. A constant is forecast by its last value (persistence). A periodic signal with period \(P\) is forecast by the value one period earlier, \(\hat s_{k+\tau}=s_{k+\tau-P}\) for \(\tau\le P\). A quasi-periodic signal, a sum of sines whose frequencies have an irrational ratio, never repeats exactly. A sum of two sines nevertheless obeys an exact linear recurrence of order four, \(s_k=\sum_{j=1}^{4}a_js_{k-j}\), because each sine \(\sin(\omega k)\) satisfies \(s_k=2\cos\omega\,s_{k-1}-s_{k-2}\). We fit the four coefficients by least squares on the past and iterate the recurrence. In the figure the past is black, the true continuation grey and the forecast dashed blue.

Code 
# three predictable signals: a constant, a periodic and a quasi-periodic one, each forecast from its past
k = np.arange(120); K0 = 80                                # the past is k < 80, the forecast covers k >= 80
P_DEMO = 20                                                # period of the periodic signal
GOLD = (1 + np.sqrt(5)) / 2                                # an irrational ratio of the two frequencies
sig_const = np.full(k.shape, 0.6)
sig_per = np.sin(2 * np.pi * k / P_DEMO)
sig_qp = np.sin(2 * np.pi * k / P_DEMO) + 0.6 * np.sin(2 * np.pi * k / (P_DEMO * GOLD))

fc_const = np.full(k.shape, sig_const[K0 - 1])             # persistence: the last value
fc_per = sig_per.copy()
for i in range(K0, len(k)):
    fc_per[i] = fc_per[i - P_DEMO]                          # repeat the value one period ago

# a sum of two sines obeys an exact linear recurrence of order 4; fit it on the past by least squares, then iterate
p = 4
X = np.stack([sig_qp[p - 1 - j:K0 - 1 - j] for j in range(p)], axis=1)
coef = np.linalg.lstsq(X, sig_qp[p:K0], rcond=None)[0]
fc_qp = sig_qp.copy()
for i in range(K0, len(k)):
    fc_qp[i] = coef @ fc_qp[i - 1:i - 1 - p:-1]

All three forecasts are exact to round-off. Such signals are trivial forecasting tasks, and a useful benchmark must be harder. Two kinds of signals are hard for different reasons. A chaotic signal is produced by known deterministic equations, without any randomness, and still cannot be forecast far ahead because small errors grow exponentially (Sections 7 to 9). A stochastic signal is irregular because each new value contains a random part that no model can know in advance.

Stochastic processes

A stochastic process is a family of random variables \(s_k\) indexed by time. The simplest one is white noise, independent values \(\varepsilon_k\) with zero mean and variance \(\sigma^2\). Its best forecast is the mean, and no model can do better. Summing white noise gives the random walk \(s_k=s_{k-1}+\varepsilon_k\), the discrete version of Brownian motion. Its variance grows as \(k\sigma^2\), so it is not stationary, and its best forecast is the last value. The autoregressive process AR(1), \(s_k=\phi s_{k-1}+\varepsilon_k\) with \(|\phi|<1\), lies in between. It forgets its past at the rate \(\phi\) per step, has the stationary variance \(\sigma^2/(1-\phi^2)\), and its best forecast \(\hat s_{k+\tau}=\phi^\tau s_k\) relaxes to the mean. It is the discrete form of the Ornstein–Uhlenbeck process, the velocity of a Brownian particle with friction. A process is (weakly) stationary when its mean and its covariances \(\mathrm{cov}(s_k,s_{k+n})\) do not depend on \(k\). The figure shows 20 realisations of each process (grey, one in blue) with \(\sigma=1\) and \(\phi=0.9\). The dashed lines are \(\pm2\) standard deviations of the process, constant for white noise and AR(1) and growing as \(2\sqrt{k}\) for the random walk.

3. Physics of the three signals

Lorenz-63 convection model

A horizontal fluid layer heated from below starts to convect when the temperature difference across it exceeds a threshold (Rayleigh–Bénard convection). Lorenz kept only the three lowest Fourier modes of the velocity and temperature fields and obtained [E. N. Lorenz, J. Atmos. Sci. 20, 130 (1963), doi:10.1175/1520-0469(1963)020<0130:DNF>2.0.CO;2] \[ \dot x=\sigma(y-x),\qquad \dot y=x(\rho-z)-y,\qquad \dot z=xy-\beta z . \] Here \(x\) measures the rate of convective circulation, \(y\) the horizontal temperature difference between rising and sinking fluid, and \(z\) the deviation of the vertical temperature profile from linear conduction. The Prandtl number \(\sigma\) is the ratio of viscosity to thermal diffusivity, \(\rho\) is the normalised Rayleigh number (the heating), and \(\beta\) is a geometric factor of the convection rolls. We use the standard values \(\sigma=10\), \(\rho=28\), \(\beta=8/3\), and we observe only \(x(t)\), sampled every \(\Delta t=0.02\) time units.

For \(\rho>1\) the vector field \(\mathbf F(\mathbf u)\), \(\mathbf u=(x,y,z)\), has three fixed points \(\mathbf F(\mathbf u^*)=0\), the conducting state at the origin and two states of steady convection \(C_\pm=(\pm\sqrt{\beta(\rho-1)},\pm\sqrt{\beta(\rho-1)},\rho-1)\) with opposite senses of rotation. Their stability follows from the eigenvalues of the Jacobian \(J_{ij}=\partial F_i/\partial u_j\) at the fixed point. A small perturbation grows along every eigenvector whose eigenvalue has a positive real part. We obtain \(J\) with jax.jacfwd and locate numerically the value \(\rho_c\) at which \(C_\pm\) lose stability.

Mackey–Glass delay equation

Mackey and Glass modelled the concentration \(x(t)\) of circulating blood cells, whose production is regulated by the concentration at an earlier time, because new cells need a maturation time \(\tau_{\rm MG}\) [M. C. Mackey and L. The RK4 scheme with step \(h=0.1\) stores this history as the vector \((x_{i-L},\dots,x_i)\) of length \(L+1\) with \(L=\tau_{\rm MG}/h\), the delay window in the generator code. For these parameters the book places the loss of stability of the fixed point (a Hopf bifurcation to a limit cycle) near \(\tau_{\rm MG}\approx4.7\) and the onset of chaos near \(\tau_{\rm MG}\approx17\). We use \(\tau_{\rm MG}=15\), 25 and 35, described in the book as a limit cycle, weak chaos and developed chaos. The signal is sampled once per time unit.

The third signal is measured. It is the output intensity of a far-infrared ammonia (NH\(_3\)) laser in a regime of chaotic pulsations, data set A of the Santa Fe Institute time-series competition. 4. Autocorrelation function

All linear statistics assume that the signal is stationary, which means that its statistical properties do not depend on the origin of time. The mean \(\mu=\langle s(t)\rangle\) is constant and the autocovariance \[ R(\tau)=\big\langle\,(s(t)-\mu)\,(s(t+\tau)-\mu)\,\big\rangle \] depends only on the lag \(\tau\), with \(R(-\tau)=R(\tau)\). The brackets denote an average over an ensemble of realisations of the process. The autocorrelation function (ACF) is the normalised autocovariance \(\rho(\tau)=R(\tau)/R(0)\), with \(\rho(0)=1\) and \(|\rho(\tau)|\le1\).

From one record of \(N\) samples we can only form time averages. The standard estimator at lag \(k\) (in samples) is \[ \hat\rho(k)=\frac{\sum_{n=1}^{N-k}(s_n-\bar s)(s_{n+k}-\bar s)}{\sum_{n=1}^{N}(s_n-\bar s)^2},\qquad \bar s=\frac1N\sum_{n=1}^N s_n . \] Replacing the ensemble average by a time average assumes ergodicity, that one long record visits all states with their ensemble weights. Our signals are stationary after the discarded transients, and the Santa Fe record is treated as stationary although its slow build-up cycles make 4000 samples a short record. The numerator divides by \(N\) and runs over \(N-k\) terms, so \(\hat\rho\) is biased towards zero at large \(k\). In return it is a positive-definite sequence, which makes it the Fourier partner of the periodogram in Section 5.

The JAX implementation below computes all lags at once with jax.vmap, and we compare it with statsmodels.tsa.stattools.acf with the same normalisation (adjusted=False).

Code 
@partial(jax.jit, static_argnums=1)
def acf_jax(x, max_lag):
    """rho_hat(k) = sum_{n<N-k} (x_n - xbar)(x_{n+k} - xbar) / sum_n (x_n - xbar)^2,  k = 0..max_lag."""
    x = x - x.mean()
    N = x.shape[0]
    n = jnp.arange(N)
    def num(k):
        # x_n x_{n+k}, with the wrapped-around terms (n >= N-k) masked out
        return jnp.sum(jnp.where(n < N - k, x * jnp.roll(x, -k), 0.0))
    return jax.vmap(num)(jnp.arange(max_lag + 1)) / jnp.dot(x, x)

5. Power spectrum

Discrete Fourier transform and periodogram

The ACF tells us how long a signal remembers, the power spectral density (PSD) tells us at which frequencies its variance sits. For a stationary signal the two are a Fourier pair (Wiener–Khinchin theorem, see the textbook of H. Kantz and T. Schreiber, Nonlinear Time Series Analysis, 2nd ed., Cambridge University Press, 2003), \[ S(f)=\int_{-\infty}^{\infty}R(\tau)\,e^{-2\pi i f\tau}\,d\tau,\qquad R(\tau)=\int_{-\infty}^{\infty}S(f)\,e^{2\pi i f\tau}\,df , \] and at \(\tau=0\) the second relation states that the total power equals the variance, \(\int S(f)\,df=R(0)\).

For \(N\) samples at spacing \(\Delta t\) the discrete Fourier transform (DFT) of the demeaned series is \[ X_q=\sum_{n=0}^{N-1}(s_n-\bar s)\,e^{-2\pi i qn/N},\qquad f_q=\frac{q}{N\Delta t},\quad q=0,1,\dots,N-1 , \] computed by the fast Fourier transform (FFT) in \(O(N\log N)\) operations. The frequencies are spaced by the resolution \(\Delta f=1/(N\Delta t)\), and only \(|f_q|\le f_{\rm Ny}=1/(2\Delta t)\) is meaningful because \(q\) and \(q-N\) describe the same sampled oscillation. A component above \(f_{\rm Ny}\) would appear at a wrong, lower frequency (aliasing). The periodogram \[ \hat S(f_q)=\frac{\Delta t}{N}\,|X_q|^2 \] estimates the two-sided density. Real signals have \(X_{-q}=X_q^*\), so we keep \(f_q\ge0\) and double all bins except \(f=0\) and \(f_{\rm Ny}\) (the one-sided PSD). With this normalisation Parseval’s theorem gives the discrete sum rule \(\sum_q\hat S(f_q)\,\Delta f=\frac1N\sum_n(s_n-\bar s)^2\), the variance of the record. The unit of \(\hat S\) is (unit of \(s\))\(^2\) per unit of frequency, and frequencies are in cycles per time unit for Lorenz and Mackey–Glass and in cycles per sample for Santa Fe.

We implement the periodogram with jnp.fft.rfft, compare it with scipy.signal.periodogram and check the sum rule.

Code 
def periodogram_jax(x, dt):
    """One-sided periodogram. X_q = sum_n (x_n - xbar) e^{-2 pi i q n / N},  S_q = (dt/N) |X_q|^2 at f_q = q/(N dt),
    doubled for 0 < f_q < f_Nyquist so that sum_q S_q df = variance (df = 1/(N dt))."""
    x = jnp.asarray(x) - jnp.mean(x)
    N = x.shape[0]
    X = jnp.fft.rfft(x)                          # q = 0 .. N/2
    S2 = dt / N * jnp.abs(X) ** 2                # two-sided density at f_q >= 0
    w = jnp.ones_like(S2).at[1:].set(2.0)
    if N % 2 == 0:
        w = w.at[-1].set(1.0)                    # the Nyquist bin appears once
    return jnp.fft.rfftfreq(N, dt), w * S2

Wiener–Khinchin theorem for the estimates

The theorem has an exact finite-\(N\) counterpart. With the biased autocovariance estimate \(\hat R(k)=\frac1N\sum_{n}(s_n-\bar s)(s_{n+k}-\bar s)\) for \(|k|<N\), the periodogram at every frequency equals \[ \hat S(f)=\Delta t\sum_{k=-(N-1)}^{N-1}\hat R(k)\,e^{-2\pi i f k\Delta t}. \] We compute \(\hat R\) through a zero-padded FFT, check it against its definition at a few lags, Fourier transform it, and compare with the periodogram on the grid \(f_q\).

Code 
def autocov_biased(x):
    """R_hat(k) = (1/N) sum_{n<N-k} (x_n - xbar)(x_{n+k} - xbar) for k = 0..N-1 (via zero-padded FFT)."""
    x = jnp.asarray(x) - jnp.mean(x)

    X = jnp.fft.fft(x, 2 * N)                    # zero padding to 2N removes the wrap-around
    return jnp.fft.ifft(jnp.abs(X) ** 2).real[:N] / N

Spectral leakage and windows

The DFT treats the record as one period of an infinitely repeated signal. If a sinusoid does not complete an integer number of cycles in the record, the periodic continuation has a jump, and the jump spreads power over all frequencies (spectral leakage). Multiplying the data by a window \(w_n\) that goes smoothly to zero at both ends removes the jump. The Hann window \(w_n=\tfrac12-\tfrac12\cos(2\pi n/N)\) is the common choice, and the windowed periodogram is \(\hat S(f_q)=\Delta t\,|\sum_n w_n(s_n-\bar s)e^{-2\pi iqn/N}|^2/\sum_n w_n^2\). The price is a wider main peak, the frequency resolution decreases by about a factor of two. The left panel shows a sinusoid with 40.5 cycles in 512 samples (orange line at its frequency), the right panel the Mackey–Glass signal at \(\tau_{\rm MG}=15\), both normalised to the maximum, without window (rectangular) and with the Hann window.

Variance of the periodogram and the Welch method

The periodogram has a serious statistical flaw. At each frequency \(\hat S(f_q)\) fluctuates around the true \(S(f_q)\) with a standard deviation equal to its mean, for any record length, because a longer record gives more frequency bins with the same scatter. For Gaussian white noise \(\hat S\) follows an exponential distribution, and we check this with \(N=4000\) samples of unit variance, whose one-sided PSD is \(S=2\). The Welch method trades resolution for variance. The record is cut into \(K\) segments of length \(L\) overlapping by \(L/2\), each segment is demeaned and Hann-windowed, and the \(K\) periodograms are averaged. The resolution becomes \(1/(L\Delta t)\) and the relative scatter drops roughly as \(1/\sqrt K\). We implement Welch in JAX, compare with scipy.signal.welch, and measure the scatter.

Code 
def welch_jax(x, dt, nperseg):
    """Welch estimate. Segments of length L = nperseg with 50% overlap, each demeaned and multiplied by the
    periodic Hann window w; S = average over segments of dt |sum_n w_n x_n e^{-2 pi i q n/L}|^2 / sum_n w_n^2."""
    x = jnp.asarray(x)
    step = nperseg // 2
    n_seg = (x.shape[0] - nperseg) // step + 1
    idx = jnp.arange(nperseg)[None, :] + step * jnp.arange(n_seg)[:, None]     # (n_seg, L) sample indices
    seg = x[idx]
    seg = seg - seg.mean(axis=1, keepdims=True)
    w = 0.5 - 0.5 * jnp.cos(2 * jnp.pi * jnp.arange(nperseg) / nperseg)        # periodic Hann window
    P = dt * jnp.abs(jnp.fft.rfft(seg * w, axis=1)) ** 2 / jnp.sum(w ** 2)
    P = P.mean(axis=0)
    P = P.at[1:-1].multiply(2.0) if nperseg % 2 == 0 else P.at[1:].multiply(2.0)  # one-sided
    return jnp.fft.rfftfreq(nperseg, dt), P, n_seg

Phase space from one coordinate

A harmonic oscillator has the state \((x,v)\), but suppose we measure only the position \(x(t)=\cos\omega t\). The finite difference \((x_k-x_{k-1})/\Delta t\) approximates the velocity, so the pair \((x_k,x_{k-\ell})\) carries the same information as \((x,v)\). The figure shows the measured signal, the true phase portrait and the delay portrait with \(\ell=20\) samples, a deformed copy of the same closed curve. For Lorenz-63 the same works with derivatives up to second order. From \(\dot x=\sigma(y-x)\) we get \(y=x+\dot x/\sigma\), then \(\dot y=\dot x+\ddot x/\sigma\) and from \(\dot y=x(\rho-z)-y\) we get \(z=\rho-(\dot y+y)/x\), so \((x,\dot x,\ddot x)\) determine \((x,y,z)\) wherever \(x\neq0\). Delays approximate these derivatives and are less sensitive to noise. This observation is due to N. H. Packard, J. P. Crutchfield, J. D. Farmer and R. S. Shaw, Phys. Rev. Lett. 45, 712 (1980), doi:10.1103/PhysRevLett.45.712.

Takens theorem

The spectra describe how the variance of a signal is distributed over frequencies. For a deterministic system we would like to see the state space itself, while we measure only one coordinate. Takens showed that this is possible [F. Takens, Lect. Notes Math. 898, 366 (1981), doi:10.1007/BFb0091924]. From the samples we form delay vectors \[ \mathbf y_n=\big(s_n,\;s_{n-\ell},\;s_{n-2\ell},\;\dots,\;s_{n-(m-1)\ell}\big)\in\mathbb R^m , \] with delay \(\ell\) (in samples) and embedding dimension \(m\). Let the dynamics take place on a smooth compact manifold of dimension \(d\) and let the measured quantity be a smooth function of the state. Takens’ theorem states that for a generic measurement function and a generic delay the map from the state to \(\mathbf y_n\) is an embedding (one-to-one, smooth, with smooth inverse on its image) whenever \(m\ge2d+1\). Sauer, Yorke and Casdagli extended the result to fractal attractors, where \(m>2d_A\) suffices with \(d_A\) the box-counting dimension of the attractor [T. Sauer, J. A. Yorke and M. Casdagli, J. Stat. Phys. 65, 579 (1991), doi:10.1007/BF01053745]. The delay vectors therefore carry the full state of the system, and a forecasting model that receives \(\mathbf y_n\) as input has all the information that the present state contains. Quantities that are invariant under smooth changes of coordinates, such as the Lyapunov exponents of Section 8, can be computed from the delay vectors.

The theorem leaves the choice of \(\ell\) and \(m\) open. If \(\ell\) is too small, consecutive coordinates are almost equal and the vectors crowd near the diagonal. If \(\ell\) is too large in a chaotic signal, the coordinates become unrelated and the reconstructed attractor dissolves. We choose \(\ell\) from the mutual information and \(m\) from false nearest neighbours.

Delay from the mutual information

A simple choice of \(\ell\) is the first zero of the ACF, at which neighbouring coordinates are linearly uncorrelated. Fraser and Swinney proposed a measure of general statistical dependence instead, the mutual information between \(s_n\) and \(s_{n+\ell}\) [A. M. Fraser and H. L. Swinney, Phys. Rev. A 33, 1134 (1986), doi:10.1103/PhysRevA.33.1134]. We divide the range of \(s\) into 16 equal bins, estimate the probability \(p_i\) of bin \(i\) and the joint probability \(p_{ij}(\ell)\) that \(s_n\) falls in bin \(i\) and \(s_{n+\ell}\) in bin \(j\), and compute \[ I(\ell)=\sum_{i,j}p_{ij}(\ell)\,\ln\frac{p_{ij}(\ell)}{p_i\,p_j}\quad\text{(in nats)} . \] \(I(\ell)\ge0\), and \(I(\ell)=0\) only for independent variables. The delay is the first local minimum of \(I(\ell)\), where the new coordinate adds the most new information while it is still dynamically related to the old one. The JAX function below builds all joint histograms with one vmap over the lags, using the same \(N-\ell_{\max}\) pairs for every lag.

Code 
@partial(jax.jit, static_argnums=(1, 2))
def mutual_information(x, max_lag, bins=16):
    """I(l) = sum_ij p_ij(l) ln[p_ij(l) / (p_i p_j)] for l = 0..max_lag, from a bins x bins histogram of the
    pairs (x_n, x_{n+l}), n = 0..N-max_lag-1 (the same pairs count for every lag)."""
    lo, hi = x.min(), x.max()
    s = jnp.clip(((x - lo) / (hi - lo) * bins).astype(jnp.int32), 0, bins - 1)     # bin index of each sample
    n = x.shape[0] - max_lag
    def mi(lag):
        a = jax.lax.dynamic_slice(s, (0,), (n,))
        b = jax.lax.dynamic_slice(s, (lag,), (n,))
        p = jnp.zeros((bins, bins)).at[a, b].add(1.0) / n                         # joint histogram p_ij
        pa, pb = p.sum(1, keepdims=True), p.sum(0, keepdims=True)                  # marginals p_i, p_j
        safe = jnp.where(p > 0, p, 1.0)
        return jnp.sum(jnp.where(p > 0, p * jnp.log(safe / (pa * pb)), 0.0))
    return jax.vmap(mi)(jnp.arange(max_lag + 1))

Embedding dimension from false nearest neighbours

If \(m\) is too small, the reconstruction folds the attractor onto itself, and points that are far apart on the attractor appear as neighbours. Kennel, Brown and Abarbanel detect this directly [M. B. Kennel, R. Brown and H. D. I. Abarbanel, Phys. Rev. A 45, 3403 (1992), doi:10.1103/PhysRevA.45.3403]. For every delay vector \(\mathbf y_i^{(m)}\) we find its nearest neighbour \(\mathbf y_j^{(m)}\), excluding all \(j\) with \(|i-j|\le w\) (Theiler window, here \(w=50\) samples), because points close in time are trivially close in space. The neighbour is false if the added coordinate separates the two points strongly, \[ \frac{|s_{i-m\ell}-s_{j-m\ell}|}{\|\mathbf y_i^{(m)}-\mathbf y_j^{(m)}\|}>R_{\rm tol}=15, \] and Kennel et al. add an absolute test, \(\|\mathbf y_i^{(m+1)}-\mathbf y_j^{(m+1)}\|/\sigma_s>A_{\rm tol}=2\), with \(\sigma_s\) the standard deviation of the signal. The fraction of false neighbours is plotted against \(m\), and it drops to a low level once the attractor is unfolded.

The neighbour search is a dense distance computation in JAX over batches of points, which we first check against the \(k\)-d tree of scipy.spatial.cKDTree.

Code 
def delay_embed(x, m, lag):
    """Rows y_n = (x_n, x_{n-l}, ..., x_{n-(m-1)l}) for n = (m-1)l .. N-1; shape (N-(m-1)l, m)."""
    n = len(x) - (m - 1) * lag
    return np.stack([x[(m - 1) * lag - j * lag:(m - 1) * lag - j * lag + n] for j in range(m)], axis=1)

@partial(jax.jit, static_argnums=2)
def nearest_neighbour(Y, w, batch=500):
    """For every row i of Y the index j of its nearest neighbour with |i - j| > w (Theiler window) and the distance."""
    n = Y.shape[0]
    idx = jnp.arange(n)
    def one(i):
        d2 = jnp.sum((Y - Y[i]) ** 2, axis=1)
        d2 = jnp.where(jnp.abs(idx - i) <= w, jnp.inf, d2)
        j = jnp.argmin(d2)
        return j, jnp.sqrt(d2[j])
    return jax.lax.map(one, idx, batch_size=batch)

def fnn_fractions(x, lag, m_max=10, w=50, r_tol=15.0, a_tol=2.0):
    """False-nearest-neighbour fractions for m = 1..m_max (Kennel et al.). Returns the ratio test alone and
    the ratio test OR the absolute test."""
    sig = x.std()
    ratio, both = [], []
    for m in range(1, m_max + 1):
        Y = delay_embed(x, m + 1, lag)               # first m columns: y_n^(m); last column: the added x_{n-ml}
        j, r = (np.asarray(a) for a in nearest_neighbour(jnp.asarray(Y[:, :m]), w))
        extra = np.abs(Y[:, m] - Y[j, m])            # |x_{i-ml} - x_{j-ml}|
        test1 = extra > r_tol * r
        test2 = np.sqrt(r ** 2 + extra ** 2) / sig > a_tol
        ratio.append(test1.mean()); both.append((test1 | test2).mean())
    return np.array(ratio), np.array(both)

7. Deterministic chaos in one dimension

Phase space, flow and dissipation

A deterministic system is defined by a state \(\mathbf u\) in a phase space and a rule that maps the present state to the future one. For a flow the rule is a differential equation \(\dot{\mathbf u}=\mathbf F(\mathbf u)\), for a map it is \(\mathbf u_{n+1}=\mathbf f(\mathbf u_n)\). A small volume \(V\) of initial conditions changes under the flow at the rate \(\dot V/V=\nabla\cdot\mathbf F\). For Lorenz-63 the divergence is constant, \(\nabla\cdot\mathbf F=-(\sigma+1+\beta)=-13.667\), so every volume shrinks by the factor \(e^{-13.667}\) per time unit. A system that contracts volumes is called dissipative. Its long-time motion lies on a set of zero volume, the attractor, which can still have a complicated, fractal structure. Chaos on such an attractor needs two ingredients, which the simplest example already shows.

Logistic map

The logistic map [R. M. May, Nature 261, 459 (1976), doi:10.1038/261459a0] \[ x_{n+1}=f(x_n)=r\,x_n(1-x_n),\qquad x_n\in[0,1],\ 0<r\le4, \] is a model of a population with limited resources. Two nearby initial conditions \(x_0\) and \(x_0+\delta_0\) separate after \(n\) steps by \(\delta_n\approx\delta_0\prod_{k<n}|f'(x_k)|\), by the chain rule. The Lyapunov exponent is the average logarithmic growth rate per step, \[ \lambda=\lim_{N\to\infty}\frac1N\sum_{n=0}^{N-1}\ln|f'(x_n)|=\big\langle\ln|r(1-2x_n)|\big\rangle . \] \(\lambda<0\) means that nearby orbits approach each other (a stable fixed point or cycle), \(\lambda>0\) that they separate exponentially (chaos). For \(r=4\) the substitution \(x=\sin^2(\pi\theta)\) turns the map into \(\theta_{n+1}=2\theta_n\) mod 1, which doubles every distance, so \(\lambda=\ln2\). We iterate the map in JAX for 1201 values of \(r\) at once with vmap, discard 1000 transient steps, keep 300 iterates for the bifurcation diagram and average \(\ln|f'|\) over 20000 steps.

@partial(jax.jit, static_argnames=("n_transient", "n_keep", "n_lyap"))
def logistic_orbit_and_lyap(r, x0=0.3, n_transient=1000, n_keep=300, n_lyap=20000):
    """Iterate x_{n+1} = r x_n (1 - x_n). Returns the last n_keep iterates after the transient and
    lambda = (1/n_lyap) sum_n ln |f'(x_n)| = <ln |r (1 - 2 x_n)|> along the orbit."""
    f = lambda x: r * x * (1.0 - x)
    x = jax.lax.fori_loop(0, n_transient, lambda i, x: f(x), x0)
    def body(x, _):
        return f(x), (x, jnp.log(jnp.abs(r * (1.0 - 2.0 * x))))
    _, (orbit, logd) = jax.lax.scan(body, x, None, length=n_lyap)
    return orbit[-n_keep:], logd.mean()

8. Lyapunov spectrum of a flow

Variational equation and the Benettin algorithm

In \(n\) dimensions a small perturbation \(\delta\mathbf u\) of a trajectory \(\mathbf u(t)\) obeys the variational equation \[ \delta\dot{\mathbf u}=J(\mathbf u(t))\,\delta\mathbf u,\qquad J_{ij}=\frac{\partial F_i}{\partial u_j}, \] with the Jacobian evaluated along the trajectory. A small sphere of perturbations becomes an ellipsoid whose semi-axes grow as \(e^{\lambda_it}\), and the rates \(\lambda_1\ge\lambda_2\ge\dots\ge\lambda_n\) are the Lyapunov exponents. By Oseledets’ multiplicative ergodic theorem [V. I. Oseledets, Trans. Moscow Math. Soc. 19, 197 (1968)] they are the same for almost all initial conditions on the attractor. Their sum is the average volume contraction rate, \(\sum_i\lambda_i=\langle\nabla\cdot\mathbf F\rangle\), and a bounded flow that is not a fixed point has one zero exponent, the direction along the trajectory.

Benettin et al. computed the whole spectrum by following \(k\) perturbation vectors at once [G. Benettin, L. Galgani, A. Giorgilli and J.-M. Strelcyn, Meccanica 15, 9 (1980), doi:10.1007/BF02128236]. Left alone, all vectors would turn towards the most unstable direction. Every interval \(T_r\) we therefore orthonormalise them by a QR decomposition, \(V=QR\), continue with the columns of \(Q\), and accumulate the logarithms of the diagonal of \(R\), which measure the growth of the successive volumes, \[ \lambda_i=\frac{1}{K\,T_r}\sum_{j=1}^{K}\ln|R^{(j)}_{ii}| . \]

Lorenz-63 spectrum

Our signal is generated by the RK4 map \(\boldsymbol\Phi_h\) with \(h=0.01\), and we compute the exponents of this map. Automatic differentiation of one RK4 step with jax.jacfwd gives the \(3\times3\) matrix \(D\boldsymbol\Phi_h\) that propagates the perturbations, with QR every \(T_r=0.1\) time units for 20000 time units. Ten independent segments of 2000 time units give the standard errors.

@partial(jax.jit, static_argnums=(2, 3))
def benettin_lorenz(u, Q, n_blocks, steps_per_block=10):
    """Benettin QR: propagate the orthonormal frame Q (3, 3) with the Jacobian of the RK4 map for
    `steps_per_block` steps, re-orthonormalise by QR, record ln |R_ii|. Returns final (u, Q) and logs (n_blocks, 3)."""
    def block(carry, _):
        u, Q = carry
        def step(c, _):
            u, Q = c
            return (lorenz_map(u), jac_map(u) @ Q), None
        (u, Q), _ = jax.lax.scan(step, (u, Q), None, length=steps_per_block)
        Q, R = jnp.linalg.qr(Q)
        return (u, Q), jnp.log(jnp.abs(jnp.diag(R)))
    return jax.lax.scan(block, (u, Q), None, length=n_blocks)

Mackey–Glass as a high-dimensional map

The state of the delay equation is the history segment, which the RK4 scheme stores as the vector \((x_{i-L},\dots,x_i)\in\mathbb R^{L+1}\), with \(L=150\), 250 and 350 for \(\tau_{\rm MG}=15\), 25 and 35. def mg_step_factory(tau, h=0.1, beta=0.2, gamma=0.1, n=10):
    """The RK4 step of the Mackey-Glass generator as a map of the delay window
    buf = (x_{i-lag}, ..., x_i) in R^{lag+1}, lag = tau/h. The same arithmetic as in `mackey_glass`."""
    f = lambda x, xd: beta * xd / (1.0 + xd ** n) - gamma * x
    def step(buf):
        x, xd0, xd1 = buf[-1], buf[0], buf[1]
        xdh = 0.5 * (xd0 + xd1)
        k1 = f(x, xd0); k2 = f(x + 0.5 * h * k1, xdh); k3 = f(x + 0.5 * h * k2, xdh); k4 = f(x + h * k3, xd1)
        return jnp.concatenate([buf[1:], (x + h / 6.0 * (k1 + 2 * k2 + 2 * k3 + k4))[None]])
    return step

Exponents from data

For the laser we know no equations, and the exponents must come from the delay vectors. Rosenstein, Collins and De Luca estimate \(\lambda_1\) directly [M. T. Rosenstein, J. J. Collins and C. J. De Luca, Physica D 65, 117 (1993), doi:10.1016/0167-2789(93)90009-P]. For each \(\mathbf y_i\) we take its nearest neighbour \(\mathbf y_{j(i)}\) outside the Theiler window and follow the distance of the two points \(k\) steps later, \[ \langle\ln d(k)\rangle=\frac{1}{N_{\rm pairs}}\sum_i\ln\big\|\mathbf y_{i+k}-\mathbf y_{j(i)+k}\big\| . \] In the range where the distance grows exponentially the curve is a straight line with slope \(\lambda_1\) per sample. Before the range the pairs align with the unstable direction, after it the distance saturates at the size of the attractor. We first apply the method to Lorenz \(x\), where we know the answer, and then to Santa Fe, with the embeddings of Section 6.

Code 
def rosenstein_curve(x, m, lag, w, k_max):
    """<ln d(k)> = mean over i of ln ||y_{i+k} - y_{j(i)+k}||, j(i) the nearest neighbour of y_i with |i - j| > w."""
    Y = delay_embed(x, m, lag)
    n = len(Y)
    j, _ = nearest_neighbour(jnp.asarray(Y), w)
    j = np.asarray(j); i = np.arange(n)
    out = []
    for k in range(k_max + 1):
        ok = (i + k < n) & (j + k < n)
        d = np.linalg.norm(Y[i[ok] + k] - Y[j[ok] + k], axis=1)
        out.append(np.log(d[d > 0]).mean())
    return np.array(out)

def slope(curve, k0, k1):
    return np.polyfit(np.arange(k0, k1 + 1), curve[k0:k1 + 1], 1)[0]

Sano and Sawada estimate the whole spectrum from data [M. Sano and Y. Sawada, Phys. Rev. Lett. 55, 1082 (1985), doi:10.1103/PhysRevLett.55.1082]. Around each point a matrix \(A_i\) is fitted by least squares to the evolution of its \(K\) nearest neighbours, \(\mathbf y_{j+1}-\mathbf y_{i+1}\approx A_i(\mathbf y_j-\mathbf y_i)\), and the Benettin QR procedure is applied to the product of these local Jacobians. We use the parameters of the book (\(m=4\), \(\ell=2\), \(K=63\), standardised data).

Code 
def local_jacobian_spectrum(x, m, lag, K, step=1):
    """Sano-Sawada estimate. For each y_i: least-squares matrix A_i with y_{j+step} - y_{i+step} ~ A_i (y_j - y_i)
    over the K nearest neighbours j; then Benettin QR on the product of the A_i. Data are standardised first.
    Returns the m exponents per sample, sorted."""
    Y = delay_embed((x - x.mean()) / x.std(), m, lag)
    N = len(Y)
    _, nb = cKDTree(Y).query(Y, k=K + 1)
    Q = np.eye(m); acc = np.zeros(m); count = 0
    for i in range(0, N - step - 1, step):
        j = nb[i, 1:]; j = j[j + step < N]
        A = np.linalg.lstsq(Y[j] - Y[i], Y[j + step] - Y[i + step], rcond=None)[0].T
        Q, R = np.linalg.qr(A @ Q)
        acc += np.log(np.abs(np.diag(R))); count += 1
    return np.sort(acc / (count * step))[::-1]

9. Kaplan–Yorke dimension and prediction horizon

The exponents also measure the size of the attractor. The sum \(\Sigma_k=\lambda_1+\dots+\lambda_k\) is the growth rate of \(k\)-dimensional volumes. Let \(j\) be the largest index with \(\Sigma_j\ge0\). Volumes of dimension \(j\) do not shrink and volumes of dimension \(j+1\) do, so the attractor has a dimension between \(j\) and \(j+1\). Kaplan and Yorke interpolated linearly between the two [J. L. Kaplan and J. A. Yorke, Lect. Notes Math. 730, 204 (1979), doi:10.1007/BFb0064319], \[ D_{\rm KY}=j+\frac{\Sigma_j}{|\lambda_{j+1}|} , \] the Kaplan–Yorke (KY) or Lyapunov dimension. Exponents that are zero within their statistical error would make the result jump between integers depending on the sign of noise, so we set exponents with \(|\lambda_i|\) below three standard errors to zero before applying the formula.

Code 
def kaplan_yorke(lams, tol=0.0):
    """D_KY = j + Sigma_j / |lambda_{j+1}|, j the largest index with Sigma_j = lambda_1 + ... + lambda_j >= 0.
    Exponents with |lambda| < tol are set to zero first (they cannot be told apart from zero)."""
    lams = np.where(np.abs(lams) < tol, 0.0, np.sort(lams)[::-1])
    cs = np.cumsum(lams)
    if cs[0] < 0:
        return 0.0
    j = int(np.max(np.nonzero(cs >= 0)[0])) + 1          # number of leading exponents with Sigma_j >= 0
    if j == len(lams):
        return np.nan                                       # not enough exponents computed
    return j + cs[j - 1] / abs(lams[j])

The leading exponent sets the prediction horizon. An initial error \(\delta_0\) grows on average as \(\delta(t)\approx\delta_0e^{\lambda_1t}\), and it reaches a tolerance \(\Delta\) after \[ T_{\rm pred}=\frac{1}{\lambda_1}\ln\frac{\Delta}{\delta_0} . \] The Lyapunov time \(T_\lambda=1/\lambda_1\) is the time for an \(e\)-fold growth. A thousand times better initial data extend the horizon by only \(\ln(1000)\,T_\lambda\approx6.9\,T_\lambda\). 11. Consequences for forecasting

The forecasting labs use horizons of 1 to 50 steps, and the Lyapunov times give the scale against which to read them. For Lorenz \(x\) the Lyapunov time is 55 samples, so the longest horizon is about one \(T_\lambda\), over which an initial error grows on average by the factor \(e^{50/T_\lambda}=2.5\). For \(\tau_{\rm MG}=25\) (\(T_\lambda\approx100\) samples) and \(\tau_{\rm MG}=35\) (\(T_\lambda\approx340\) samples) all horizons lie well within one Lyapunov time (error growth by the factors 1.64 and 1.16 over 50 steps), and the limit to forecasting comes from how well a model learns the dynamics. The periodic \(\tau_{\rm MG}=15\) has no finite Lyapunov time, and a model that captures its line spectrum can forecast it at all horizons. The laser has the shortest Lyapunov time, 34 samples from the Rosenstein estimate and 15 from the local Jacobians, so the horizon of 50 steps spans 1.5 to 3.2 Lyapunov times and an initial error grows by a factor between 4.3 and 26 over it. Forecasts of the laser must lose skill within the tested range.

The embedding sets the length of the input window. A model that receives the delay vector with \(m\) entries at spacing \(\ell\) sees a window of \((m-1)\ell+1\) samples, 31 samples for Lorenz \(x\), 49 for \(\tau_{\rm MG}=25\), 79 for \(\tau_{\rm MG}=35\) and 5 for Santa Fe. Shorter windows leave states unresolved, and for Mackey–Glass the window must reach back over the delay of the equation.

The exponents and the dimensions point to nonlinear models. All three chaotic signals have a positive leading Lyapunov exponent and attractors with \(D_{\rm KY}\) between 2 and 3.5. In the logistic map of Section 7 such sensitivity arises from stretching and folding, and a linear model fitted to these signals can reproduce their spectra but no folding. Linear autoregressive models are therefore baselines for these signals, and the gain of a nonlinear model, the nonlinear vector autoregression of Lab 034 and the recurrent networks of Lecture 8, is expected where the folding acts, at the lobe switches of Lorenz and at the collapses of the laser. The surrogate test of Appendix A supports the same conclusion with a hypothesis test, in which the nearest-neighbour prediction error rejects the linear Gaussian null model for all three chaotic signals.

Same spectrum, different dynamics

The ACF and the PSD are second-order statistics, and many different processes share them. We make this concrete by constructing a random signal with the same periodogram as Lorenz \(x\). We take the DFT \(X_q\) of the data, keep the amplitudes \(|X_q|\), replace the phases by independent random phases, and transform back. Such a signal is called a phase-randomised surrogate [J. Theiler, S. Eubank, A. Longtin, B. Galdrikian and J. D. Farmer, Physica D 58, 77 (1992), doi:10.1016/0167-2789(92)90102-S].

Code 
def phase_randomised(x, key):
    """Fourier-transform surrogate. X_q = FFT of the demeaned series; keep |X_q|, replace the phases by independent
    uniform phases on [0, 2 pi) (zero phase at f = 0 and, for even N, at the Nyquist frequency, so that the inverse
    transform is real); inverse FFT and add the mean back. The periodogram is unchanged."""
    N = x.shape[0]
    X = jnp.fft.rfft(x - x.mean())                       # rfft stores q = 0..N/2; q < 0 follow from X_{-q} = conj(X_q)
    phi = jax.random.uniform(key, X.shape, minval=0.0, maxval=2 * jnp.pi)
    phi = phi.at[0].set(0.0)
    if N % 2 == 0:
        phi = phi.at[-1].set(0.0)
    return jnp.fft.irfft(jnp.abs(X) * jnp.exp(1j * phi), N) + x.mean()

Phase-randomised surrogates

The next null hypothesis is the one relevant for forecasting. It states that the data are a realisation of a stationary linear Gaussian process, \[ H_0:\quad s_n=\mu+\sum_{j\ge0}h_j\,\eta_{n-j},\qquad \eta_n\ \text{independent}\ \mathcal N(0,1), \] possibly observed through a static monotone function \(g\), \(\tilde s_n=g(s_n)\). Such a process is fully described by its mean and its spectrum, which is set by the coefficients \(h_j\). A linear Gaussian process has random, independent Fourier phases, so its surrogates are generated in four operations. We compute \(X_q\) with the FFT, keep \(|X_q|\), draw phases \(\phi_q\) uniformly on \([0,2\pi)\) with \(\phi_{-q}=-\phi_q\) so that the inverse transform is real (and zero phase at \(f=0\) and at \(f_{\rm Ny}\)), and apply the inverse FFT. Time-reversal asymmetry

A linear Gaussian process looks statistically the same when played backwards, because all its properties follow from \(R(\tau)=R(-\tau)\). Many nonlinear systems are visibly irreversible. The Santa Fe laser builds up its pulsations slowly and loses them suddenly, and the reversed record would show sudden onsets and slow decays. A simple statistic that detects irreversibility is the skewness of the increments \(d_k=s_{k+1}-s_k\), \[ Q=\frac{\langle d_k^3\rangle}{\langle d_k^2\rangle^{3/2}} . \] Time reversal changes the sign of every increment and hence of \(Q\), so a time-reversible process has \(Q=0\) up to finite-sample fluctuations. A static monotone measurement function keeps a reversible process reversible, so \(Q\) is a valid statistic under the extended null hypothesis.

Code 
def q_stat(s):
    """Time-reversal asymmetry Q = <d^3> / <d^2>^{3/2}, d_k = s_{k+1} - s_k (skewness of the increments)."""
    d = jnp.diff(s)
    return jnp.mean(d ** 3) / jnp.mean(d ** 2) ** 1.5

Rank test

The test compares the value \(Q_{\rm data}\) with the values \(Q_1,\dots,Q_M\) of \(M\) surrogates. Under \(H_0\) the data and the surrogates are exchangeable, so each of the \(M+1\) values is equally likely to be the largest or the smallest. We do not know the sign of the asymmetry in advance, so we use a two-sided test with \(M=39\). We reject \(H_0\) when \(Q_{\rm data}\) is the smallest or the largest of the 40 values, which happens under \(H_0\) with probability \(2/40=0.05\). The rank is the position of \(Q_{\rm data}\) among the 40 values (1 is the smallest). As a secondary number we report \(z=(Q_{\rm data}-\bar Q_{\rm surr})/\sigma_{\rm surr}\), computed with 200 surrogates, which also give the histograms. The decision uses only the first 39 surrogates.

Amplitude-adjusted surrogates and a prediction statistic

The phase-randomised surrogates have Gaussian value distributions, while the data do not. A rejection could then come from the static measurement function alone. Schreiber and Schmitz introduced the iterative amplitude-adjusted Fourier-transform (IAAFT) surrogates, which keep the exact value distribution and the spectrum up to a small error [T. Schreiber and A. Schmitz, Phys. Rev. Lett. 77, 635 (1996), doi:10.1103/PhysRevLett.77.635]. Starting from a shuffle of the data, the algorithm alternates two projections. It imposes the Fourier amplitudes of the data while keeping the current phases, and then it replaces the values by the data values of the same rank.

As a statistic sensitive to determinism we use the error of a nearest-neighbour forecast in the delay space of Section 6. For each delay vector \(\mathbf y_n\) we find its nearest neighbour \(\mathbf y_j\) outside the Theiler window and predict \(\hat s_{n+1}=s_{j+1}\). The statistic is the normalised error \(E={\rm rms}(s_{n+1}-\hat s_{n+1})/\sigma_s\). A deterministic signal is predicted well by its neighbours, a linear stochastic one much worse. The data error is expected to be smaller, so the test is one-sided with \(M=19\) and we reject \(H_0\) if the data error is the smallest of the 20 values (probability \(1/20=0.05\) under \(H_0\)). For AR(2) we use \(m=3\), \(\ell=2\).

def iaaft(x, key, n_iter=200):
    """Iterative amplitude-adjusted Fourier-transform surrogate (Schreiber and Schmitz). Start from a random
    permutation of x; repeat (i) impose the Fourier amplitudes |X_q| of x keeping the current phases,
    (ii) impose the values of x by rank ordering. Ends with step (ii): exact value distribution, approximate spectrum."""
    N = x.shape[0]
    amp = jnp.abs(jnp.fft.rfft(x))
    x_sorted = jnp.sort(x)
    def body(_, s):
        S_ = jnp.fft.rfft(s)
        s = jnp.fft.irfft(amp * jnp.exp(1j * jnp.angle(S_)), N)
        return x_sorted[jnp.argsort(jnp.argsort(s))]          # the value of x with the same rank as s_n
    return jax.lax.fori_loop(0, n_iter, body, jax.random.permutation(key, x))

iaaft_batch = jax.jit(jax.vmap(iaaft, in_axes=(None, 0)))

def nn_prediction_error(s, m, lag, h=1, w=50):
    """Normalised error of the nearest-neighbour predictor: s_{n+h} is predicted by s_{j+h}, j the nearest
    neighbour of the delay vector y_n with |n - j| > w. Returns rms(error) / std(target)."""
    Y = delay_embed(s, m, lag)[:-h]
    target = s[(m - 1) * lag + h:]
    j, _ = nearest_neighbour(jnp.asarray(Y), w)
    err = target - target[np.asarray(j)]
    return float(np.sqrt(np.mean(err ** 2)) / target.std())

Summary

We characterised three signals that serve as benchmarks for forecasting. Constant, periodic and quasi-periodic signals are forecast exactly from their past, white noise at best by its mean and the random walk by its last value. Chaotic signals are deterministic, and their forecasts are still limited by the exponential growth of small errors. Lorenz-63 is a three-mode model of convection whose two convective fixed points lose stability at \(\rho_c=24.737\). Mackey–Glass is a delay equation with an infinite-dimensional state, here periodic at \(\tau_{\rm MG}=15\) and chaotic at 25 and 35. The Santa Fe record is the intensity of a chaotic NH\(_3\) laser described by the Maxwell–Bloch equations.

The ACF and the PSD are a Fourier pair, which holds also for the finite-sample estimates. The periodogram needs a window against leakage and averaging (Welch) against its large variance. The periodic Mackey–Glass signal has a line spectrum with the strongest line at period \(\approx3\tau_{\rm MG}\) and its fundamental at twice that period. The chaotic signals have broadband spectra, Santa Fe with a pulsation peak at 7.26 samples.

Delay vectors \((s_n,s_{n-\ell},\dots,s_{n-(m-1)\ell})\) reconstruct the state space (Takens). The mutual information gives the delay \(\ell\) and false nearest neighbours the dimension \(m\). Chaos arises from stretching and folding, as the logistic map shows with \(\lambda=\ln2\) at \(r=4\). The Benettin QR algorithm with JAX derivatives of the integration step gives the Lorenz spectrum \((0.907,0,-14.573)\) with the exact Liouville sum and the Mackey–Glass spectra in state spaces of up to 351 dimensions, both in agreement with the book within statistical errors. From data, Rosenstein and Sano–Sawada estimates of \(\lambda_1\) for the laser differ by a factor of two, and the method must be stated with the number. The Kaplan–Yorke dimension turns the spectrum into an attractor dimension, 2.06 for Lorenz and 3.16 and 3.41 for the chaotic Mackey–Glass signals, and the Lyapunov time sets the prediction horizon \(T_{\rm pred}=\lambda_1^{-1}\ln(\Delta/\delta_0)\), confirmed by the error growth of nearby Lorenz trajectories.

The optional Appendix A turns the difference between chaos and coloured noise with the same spectrum into a hypothesis test. Phase-randomised and amplitude-adjusted surrogates realise the linear Gaussian null model, a statistic such as the time-reversal asymmetry or the nearest-neighbour prediction error measures what the null model lacks, and the rank of the data among the surrogates decides. The prediction error rejects the null model for all three chaotic signals and keeps it for a linear AR(2) control, while the time-reversal asymmetry at lag one rejects only Mackey–Glass, which shows that the result depends on the statistic.
