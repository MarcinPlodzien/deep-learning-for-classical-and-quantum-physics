Lab 023 — The SK spin glass without labels

Lab 032 introduced the Sherrington–Kirkpatrick (SK) spin glass: \(N\) Ising spins, every pair coupled by a Gaussian random coupling \(J_{ij}\sim\mathcal N(0,J^2/N)\). Below \(T_c=J\) the spins freeze in random directions. The magnetisation stays zero, a snapshot of the frozen phase looks like noise, and the order is visible only when two replicas (independent copies with the same couplings) are compared through their overlap \(q=\frac1N\sum_is_i^as_i^b\). Lab 032 located the transition with the Binder cumulant of \(q\): for the sizes \(N=32,64,128\) the curves cross between \(T\approx0.87\) and \(0.92\), with wide statistical intervals that contain \(T_c=J\).

The transition at \(T_c=J\) is continuous and of mean-field type, since every spin interacts with all others. It is not signalled by the magnetisation, which is zero in both phases, nor by the ordinary magnetic susceptibility, but by the divergence of the spin-glass susceptibility \(\chi_{\rm SG}=\frac1N\sum_{ij}[\langle s_is_j\rangle^2]=1/(1-\beta^2J^2)\) as \(T\to J\) from above (\(\beta=1/T\)). Below \(T_c\) the replica symmetry is broken (Parisi): the Boltzmann distribution splits into many valleys. In the Ising ferromagnet, by contrast, the magnetisation becomes non-zero below \(T_c\) and its own susceptibility diverges.

In the previous labs of this lecture the same two unsupervised methods, principal component analysis (PCA) and autoencoder anomaly detection, found the magnetisation of the Ising model and both order parameters of the \(J_1\)–\(J_2\) model directly from raw snapshots. The spin glass is a harder test, for a reason we can state before computing anything: Lab 032 proved that single snapshots pooled over disorder samples are exactly uniformly random strings of signs at every temperature. A method that receives single snapshots therefore has nothing to find, however powerful it is. This notebook follows the same protocol as the previous ones. We first confirm that single snapshots carry no signal and see how a finite data set can nevertheless fool us. We then give the methods the gauge-invariant input that Lab 032 identified, the overlap field \(q_i=s_i^as_i^b\), and ask what PCA and the autoencoder learn from it, where their signals sit relative to \(T_c=J\), and how they change with \(N\). Finally we run the same detectors on the Mattis model, which has random signs but no frustration, as a control with a sharp, ferromagnet-like transition.

The units are those of Lab 032: \(k_B=1\), \(J=1\), temperatures in units of \(J\). Square brackets \([\,\cdot\,]\) denote the average over disorder samples, angular brackets \(\langle\cdot\rangle\) the thermal average in one sample.

1. The data set and the reference result

Each file data/sk_N{N}.npz of Lab 032 holds Monte Carlo snapshots for \(D\) disorder samples, produced by parallel tempering: for every sample, copies of the system at a ladder of temperatures are simulated together and neighbouring copies exchange their configurations from time to time, so that a configuration trapped in a valley at low temperature can escape through high temperatures and come back in another valley. The array configs has shape (D, 2, K, S, N): sample, replica \(a\) or \(b\), temperature, snapshot, spin, with \(K=25\) temperatures \(T=0.40,0.45,\dots,1.60\) and \(S=32\) snapshots per replica, separated by 64 Monte Carlo sweeps. The couplings of every sample are stored too, but we will not use them: the methods only see spins. The array q_int holds \(Nq_{ab}\) measured every 4 sweeps, 512 values per sample and temperature; we use it once, to reproduce the Binder-cumulant result of Lab 032 that serves as the reference.

The reference is the Binder cumulant of the overlap, \[ g(T,N)=\frac12\left(3-\frac{[\langle q^4\rangle]}{[\langle q^2\rangle]^2}\right), \] which is \(0\) for a Gaussian overlap distribution (paramagnet) and \(1\) for two sharp peaks. Finite-size scaling makes \(g(T_c,N)\) independent of \(N\), so the curves for different sizes cross at \(T_c\). The functions below compute \(g\) from per-sample moments, the crossing temperature of two curves by linear interpolation, and a bootstrap over disorder samples: 200 resamplings of the \(D\) samples with replacement, in which the two moments of a sample always stay together because they are measured on the same sample. The same functions will be applied later to quantities learned by the unsupervised methods, so that every result is compared with the reference in the same way.

Code 
def binder(m2, m4):
    """Binder cumulant from per-sample thermal moments m2, m4 of shape (D, K)."""
    return 0.5 * (3 - m4.mean(0) / m2.mean(0) ** 2)

def crossing(T, g1, g2, window=(0.6, 1.4)):
    """Temperature in the window where g1 - g2 changes sign (linear interpolation); NaN if it does not."""
    sel = (T >= window[0]) & (T <= window[1])
    T, dlt = T[sel], (g1 - g2)[sel]
    i = np.where(np.sign(dlt[:-1]) != np.sign(dlt[1:]))[0]
    if len(i) == 0:
        return np.nan
    i = i[0]
    return T[i] - dlt[i] * (T[i + 1] - T[i]) / (dlt[i + 1] - dlt[i])

def crossing_table(moments, n_boot=200, seed=7):

    return out, g_boot

Every observable of this notebook has two forms: its definition through the partition function, and the estimator that the code evaluates. For one coupling sample \(J\) the thermal average is \(\langle A\rangle_J=Z_J^{-1}\sum_{\boldsymbol s}A(\boldsymbol s)\,e^{-\beta H_J(\boldsymbol s)}\) with \(Z_J=\sum_{\boldsymbol s}e^{-\beta H_J(\boldsymbol s)}\), and the disorder average over the \(D\) samples of a data set is \([X]=\frac1D\sum_{d=1}^DX_{J_d}\). The Monte Carlo data replace each thermal average by a mean over \(n\) measurements of sample \(d\), \(\overline{x}_d=\frac1n\sum_{k=1}^nx_{d,k}\), where \(q_{d,k}\) is the overlap of the \(k\)-th replica pair; we write \(\widehat{[q^p]}=\frac1D\sum_d\overline{q^p}_d\).

2. Single snapshots

2.1 Consequences of the gauge symmetry

Lab 032 (Section 8.1) showed that the gauge transformation \(s_i\to\tau_is_i\), \(J_{ij}\to\tau_i\tau_jJ_{ij}\) leaves the distribution of the couplings unchanged, so that the distribution of a single snapshot, pooled over disorder samples, is \([p_J(\boldsymbol s)]=2^{-N}\) at every temperature. Two consequences matter for a data set. First, snapshots from different samples are independent, so a data set with one snapshot per sample is a set of independent, uniformly random strings of signs, in the paramagnet and in the spin glass alike: every statistic computed from it has the same distribution at every temperature. Second, snapshots of the same sample are not independent. Below \(T_c\) two snapshots of one sample are frozen in the same or related valleys, and their overlap is large. A data set with many snapshots per sample therefore contains replica pairs in disguise, and a method can pick up the low-temperature structure from them. We test both statements with PCA.

2.2 PCA of single snapshots

PCA diagonalises the covariance matrix of the data. For a data matrix \(X\) of shape (M, N) (one snapshot per row) with column means \(\bar{\boldsymbol x}\), \[ C=\frac{1}{M-1}(X-\bar{\boldsymbol x})^T(X-\bar{\boldsymbol x}),\qquad C\,\boldsymbol\lambda_l=\sigma_l^2\boldsymbol\lambda_l,\qquad \sigma_1^2\ge\sigma_2^2\ge\dots, \] where the unit eigenvectors \(\boldsymbol\lambda_l\) are the principal directions and the eigenvalues \(\sigma_l^2\) the variances along them; the projection of a data vector \(\boldsymbol x\) on the \(l\)-th direction is \(w^{(l)}=\boldsymbol\lambda_l^T(\boldsymbol x-\bar{\boldsymbol x})\). These variances carry a component index \(l\) and are unrelated to the Mattis spins \(\sigma_i\) of Section 4 and to the spread \(\sigma_{\rm train}\) of the anomaly score. Since \(N\le128\) is small, we diagonalise the \(N\times N\) matrix \(C\) directly with jnp.linalg.eigh, which is much faster on the CPU than a singular value decomposition of the long data matrix. The largest eigenvalue \(\sigma_1^2\) is the variance of the data along the most important direction. For independent uniform strings \(C\) is the identity plus sampling noise, and \(\sigma_1^2\) fluctuates around the upper edge of the Marchenko–Pastur distribution, \((1+\sqrt{N/M})^2\). Instead of relying on this asymptotic formula we compare with the same computation on uniformly random strings of the same shape (40 draws, mean and two standard deviations).

At every temperature we compute \(\sigma_1^2\) for two data sets of the \(N=128\) samples: one snapshot per sample (\(M=D\)), and all \(2\times32\) snapshots of every sample (\(M=64D\)).

Code 
@jax.jit
def pca_jax(X):
    """PCA by diagonalising the covariance matrix. X: (M, N).
    Returns the mean (N,), variances sigma_l^2 in decreasing order (N,), principal directions (N, N) with rows lambda_l."""
    mu = X.mean(0)
    Xc = X - mu
    C = Xc.T @ Xc / (X.shape[0] - 1)                     # (N, N) covariance matrix
    lam, V = jnp.linalg.eigh(C)                          # ascending eigenvalues, eigenvectors in columns
    return mu, lam[::-1], V[:, ::-1].T

def top_variance(X):
    return float(pca_jax(jnp.asarray(X, jnp.float32))[1][0])

def random_null(M, N, n_draw=40, seed=0):
    """Mean and standard deviation of sigma_1^2 for uniformly random +-1 strings of shape (M, N)."""
    rng = np.random.default_rng(seed)
    v = [top_variance(rng.choice([-1.0, 1.0], size=(M, N))) for _ in range(n_draw)]
    return np.mean(v), np.std(v)

2.3 An autoencoder on single snapshots

The anomaly-detection protocol of the previous labs trains an autoencoder on one region and maps its reconstruction error. We use a dense autoencoder, because the SK model has no lattice: the label \(i\) of a spin carries no geometry, so convolutions have nothing to exploit. The encoder maps \(\boldsymbol s\in\{-1,1\}^N\) through a hidden layer of 64 rectified linear units (ReLU) to a latent vector \(\boldsymbol z\), and the decoder maps \(\boldsymbol z\) back through 64 ReLU units to \(\hat{\boldsymbol s}\in[-1,1]^N\) with a final \(\tanh\). The reconstruction error of one input is \[ \varepsilon(\boldsymbol x)=\frac1N\sum_{i=1}^N(x_i-\hat x_i)^2 , \] and the loss is its mean over a mini-batch of inputs, the mean squared error between input and reconstruction. It is minimised with Adam (adaptive moment estimation), a gradient-descent method that scales the step of every parameter by running averages of its past gradients and their squares, with learning rate \(10^{-3}\). For speed the whole training epoch is compiled into one function with jax.lax.scan over mini-batches. Every training set is augmented by the global flip \(\boldsymbol x\to-\boldsymbol x\), a symmetry of the Hamiltonian.

A memorising network could reconstruct the snapshots of the samples it was trained on without learning anything general. We therefore split the disorder samples into two halves (even and odd sample index) and evaluate on samples that the network has never seen. Two single-snapshot autoencoders are trained on the even samples: one on the paramagnet (\(T\ge1.3\), latent dimension 8), one on the frozen phase (\(T\le0.6\), latent dimension 16, enough to store frozen patterns).

class DenseAE(nnx.Module):
    """Dense autoencoder n_in -> hidden -> latent -> hidden -> n_in; output tanh (spins) or linear."""
    def __init__(self, n_in, latent, hidden=64, out="tanh", *, rngs):
        self.e1 = nnx.Linear(n_in, hidden, rngs=rngs); self.e2 = nnx.Linear(hidden, latent, rngs=rngs)
        self.d1 = nnx.Linear(latent, hidden, rngs=rngs); self.d2 = nnx.Linear(hidden, n_in, rngs=rngs)
        self.out = out
    def encode(self, x):
        return self.e2(nnx.relu(self.e1(x)))
    def __call__(self, x):
        y = self.d2(nnx.relu(self.d1(self.encode(x))))
        return jnp.tanh(y) if self.out == "tanh" else y

def train_ae(X, latent, epochs, hidden=64, out="tanh", batch=256, lr=1e-3, seed=0):
    """Train a DenseAE on X (M, n_in) with Adam; one compiled lax.scan per epoch. Returns the model and the loss per epoch."""
    X = jnp.asarray(X, jnp.float32)
    model = DenseAE(X.shape[1], latent, hidden, out, rngs=nnx.Rngs(seed))
    graph, params = nnx.split(model, nnx.Param)
    tx = optax.adam(lr); opt_state = tx.init(params)
    n_b = X.shape[0] // batch
    loss_fn = lambda p, x: jnp.mean((nnx.merge(graph, p)(x) - x) ** 2)

    @jax.jit
    def epoch(p, o, key):
        perm = jax.random.permutation(key, X.shape[0])[: n_b * batch].reshape(n_b, batch)   # (n_b, batch) indices
        def body(carry, idx):
            p, o = carry
            l, g = jax.value_and_grad(loss_fn)(p, X[idx])
            u, o = tx.update(g, o, p)
            return (optax.apply_updates(p, u), o), l
        (p, o), ls = jax.lax.scan(body, (p, o), perm)
        return p, o, ls.mean()

    key, hist = jax.random.PRNGKey(seed), []
    for _ in range(epochs):
        key, k = jax.random.split(key)
        params, opt_state, l = epoch(params, opt_state, k)
        hist.append(float(l))
    return nnx.merge(graph, params), np.array(hist)

3. Overlap fields

3.1 The gauge-invariant input

For two replicas \(a,b\) of the same sample the overlap field is \[ q_i=s_i^a s_i^b\in\{-1,1\},\qquad i=1,\dots,N,\qquad q=\frac1N\sum_iq_i . \] It is invariant under the gauge transformation (\(\tau_i^2=1\)), and Lab 032 showed that the pooled distribution of pairs depends on the configurations only through \(\boldsymbol q\), and, because the SK ensemble is also symmetric under permutations of the spin labels, only on the number of \(+1\) entries, i.e. on \(q\). Every \((\boldsymbol s^a,\boldsymbol s^b)\) pair of the data set gives one overlap field. Pairing snapshot \(t\) of replica \(a\) with snapshot \(t'\) of replica \(b\) for all \(t,t'\) gives \(32\times32=1024\) fields per sample and temperature; the 32 simultaneous pairs \(t=t'\) are used for training, all 1024 pairs for measurements. A field is a vector of length \(N\), so the data matrices have shape (pairs, N). The flip of one replica, \(\boldsymbol q\to-\boldsymbol q\), is an exact symmetry and is used for augmentation.

A consequence of the permutation symmetry should be kept in mind from the start. A function of one overlap field that does not depend on the order of the spins can depend only on the number of \(+1\) entries, that is, on \(q\). Any permutation-invariant summary of one field is a function of \(q\) alone. A permutation-invariant network would therefore be forced to learn some function of \(q\); we will see that the unconstrained dense networks arrive there too.

def overlap_fields(c, idx, k, all_pairs=False):
    """Overlap fields of samples idx at temperature slot k. c: (D, 2, K, S, N).
    Simultaneous pairs: (len(idx) * S, N); all pairs (t, t'): (len(idx) * S * S, N)."""
    a, b = c[idx, 0, k], c[idx, 1, k]                                   # (n, S, N) each
    if all_pairs:
        return (a[:, :, None, :] * b[:, None, :, :]).reshape(-1, a.shape[-1])
    return (a * b).reshape(-1, a.shape[-1])

3.2 PCA of overlap fields

We pool the simultaneous-pair overlap fields of all samples and all 25 temperatures, add their mirror images \(-\boldsymbol q\), and run PCA; the method receives neither the temperature nor the sample index. Before looking at the result we can predict it. Because the pooled distribution is symmetric under permutations of the labels and under \(\boldsymbol q\to-\boldsymbol q\), the covariance matrix has the form \(C_{ij}=\delta_{ij}+(1-\delta_{ij})\,c\) with one number \(c\). Its eigenvectors are the uniform vector \(\boldsymbol\lambda_1=(1,\dots,1)/\sqrt N\) and the \(N-1\) vectors orthogonal to it. The projection on the uniform vector is the overlap itself, \[ w^{(1)}=\boldsymbol\lambda_1^T\boldsymbol q=\sqrt N\,q,\qquad \sigma_{\rm uniform}^2=\boldsymbol\lambda_1^TC\,\boldsymbol\lambda_1=N\,\overline{q^2}, \] where \(\overline{q^2}\) is the mean of \(q^2\) over the pooled data. Evaluated at a single temperature, \(N[\langle q^2\rangle]\) is the spin-glass susceptibility \(\chi_{\rm SG}\) of Lab 032. The PCA implementation in JAX from Section 2 is checked against sklearn.decomposition.PCA on the same data: the explained-variance ratios and the principal directions must agree, the directions up to a sign.

3.3 An autoencoder on overlap fields

The anomaly-detection protocol of Lab 019 trains on a well-structured phase. Here that is the frozen phase, \(T\le0.6\), where the fields are mostly \(+1\) or mostly \(-1\) with scattered exceptions. The autoencoder has a latent dimension of one, so it must compress each field into a single number; everything else is as in Section 2.3. We use two folds: the network trained on the even samples is evaluated on the odd ones and vice versa, so every sample is evaluated by a network that never saw it.

Before training we can predict the best such a network can do. If it encodes the overlap \(q\) and outputs the constant vector \(\hat q_i=q\), the error is \[ \varepsilon=\frac1N\sum_i(q_i-q)^2=1-q^2, \] because \(q_i^2=1\) and \(\frac1N\sum_iq_i=q\). Positions of the exceptional spins are sample-specific and, as Section 2.3 showed, do not transfer to new samples. We therefore expect a mean error \(\bar\varepsilon(T)\approx1-[\langle q^2\rangle]\), an anomaly signal that is a known physical observable.

3.4 Anomalies at the level of the overlap distribution

The single-field autoencoder can only learn \(q\). The physics of the spin glass is richer: below \(T_c\) the overlap distribution \(P_J(q)\) of each sample is broad, with weight between its peaks, and it differs from sample to sample. To let a network see this, we give it one input vector per sample and temperature: the histogram of \(|q|\) over the 1024 pairs, in 16 bins of width \(1/16\) on \([0,1]\). The histogram is invariant under permutations of the spins and of the snapshots, and it is the natural input when the object of interest is a distribution. The input has shape (16,), the data set has (D, K, 16).

The anomaly detector is trained on the paramagnet, \(T\ge1.3\), where every \(P_J(q)\) is a narrow Gaussian around \(0\) and the hypothesis “nothing happens here” is safe. The autoencoder has a hidden layer of 32 units, a latent dimension of 2, and a linear output. As anomaly score we use the error in units of its spread on the training data, \[ a(\text{sample},T)=\frac{\varepsilon-\mu_{\rm train}}{\sigma_{\rm train}}, \] evaluated, as before, on held-out samples with two folds. A score above \(3\) means that the histogram is unlike any typical paramagnetic histogram.

def abs_q_histograms(c, n_bins=16):
    """Histogram of |q| over all S*S pairs, for every sample and temperature: (D, K, n_bins)."""
    D, _, K, S, N = c.shape
    H = np.zeros((D, K, n_bins))
    for k in range(K):
        q = np.einsum("dsi,dti->dst", c[:, 0, k], c[:, 1, k]).reshape(D, -1) / N         # (D, S*S)
        idx = np.minimum((np.abs(q) * n_bins).astype(int), n_bins - 1)
        H[:, k] = np.stack([(idx == b).mean(1) for b in range(n_bins)], axis=1)
    return H

def histogram_anomaly(H, seed=0):
    """Two-fold anomaly score of per-sample histograms H (D, K, n_bins); detector trained on T >= 1.3. Returns (D, K)."""

def onset(T, s, level):
    """Highest temperature at which the mean score s(T) reaches `level`, scanning down from high T (linear interpolation)."""
    above = np.where(s >= level)[0]
    if len(above) == 0:
        return np.nan
    i = above.max()
    if i == len(T) - 1:
        return T[-1]
    return T[i] + (level - s[i]) * (T[i + 1] - T[i]) / (s[i + 1] - s[i])

The score rises from zero well above \(T_c\), and the temperature at which it reaches a given level increases with \(N\) (printed above): for the largest size the detector raises the alarm at the highest temperature. This is not a failure of the network; it is what the physics says. Above \(T_c\) the width of \(P_J(q)\) is set by the spin-glass susceptibility, \([\langle q^2\rangle]=\chi_{\rm SG}/N\) with \(\chi_{\rm SG}=1/(1-\beta^2J^2)\), which grows continuously as \(T\) decreases towards \(J\). The detector notices this growth as soon as it is larger than the sample-to-sample noise of the training histograms, and that noise decreases as the histograms become more precise. An anomaly onset is therefore not a transition temperature: it depends on the threshold, on the training window, and on the statistical resolution of the data. A mean-field transition, approached by a smooth growth of fluctuations on both sides, gives an autoencoder no sharp edge to find.

4. The Mattis model as a control

Mattis couplings \(J_{ij}=\frac JN\xi_i\xi_j\) with random fixed signs \(\xi_i=\pm1\) look as random as SK couplings, but Lab 032 (Section 7) showed that the gauge transformation \(\sigma_i=\xi_is_i\) turns the model into the Curie–Weiss ferromagnet. This gives an exact sampler. In the Curie–Weiss model the energy depends only on the magnetisation \(M=\sum_i\sigma_i\), so the probability of \(M\) is \[ P(M)\propto\binom{N}{(N+M)/2}\exp\!\left[\frac{\beta J}{2N}\left(M^2-N\right)\right], \] and given \(M\) all configurations with that magnetisation are equally likely. We draw \(M\) from \(P(M)\), place its \((N+M)/2\) up-spins at random positions, and multiply by \(\xi\) to obtain an exact equilibrium Mattis snapshot, with no Monte Carlo and no equilibration question. The overlap field of two replicas is \(s_i^as_i^b=\sigma_i^a\sigma_i^b\), independent of \(\xi\): the hidden pattern drops out, exactly as the couplings drop out for the SK overlap field. We generate a data set with the same shape as the SK data and check the sampler against the exact moment \(\langle\sigma_i\sigma_j\rangle=(\langle M^2\rangle-N)/(N(N-1))\) for \(i\neq j\).

Code 
def cw_probabilities(N, T):
    """Exact P(M) of the Curie-Weiss model, M = 2 n_up - N, for J = 1: array (N + 1,) over n_up = 0..N."""
    n = np.arange(N + 1); M = 2 * n - N
    logw = gammaln(N + 1) - gammaln(n + 1) - gammaln(N - n + 1) + (M**2 - N) / (2 * N * T)
    p = np.exp(logw - logw.max())
    return p / p.sum()

def mattis_dataset(N, D, S=32, seed=0):
    """Exact equilibrium Mattis snapshots with the layout of the SK data: (D, 2, K, S, N) float32."""
    rng = np.random.default_rng(seed)
    xi = rng.choice([-1.0, 1.0], size=(D, 1, 1, 1, N))                              # hidden pattern of every sample
    out = np.empty((D, 2, K_T, S, N), np.float32)
    for k, T in enumerate(T_GRID):
        n_up = rng.choice(N + 1, size=(D, 2, S), p=cw_probabilities(N, T))             # magnetisations
        rank = np.argsort(rng.random((D, 2, S, N)), axis=-1).argsort(axis=-1)          # a random permutation per configuration
        out[:, :, k] = np.where(rank < n_up[..., None], 1.0, -1.0)                     # n_up up-spins at random positions
    return out * xi, xi[:, 0, 0, 0]                                                    # s_i = xi_i sigma_i;  xi: (D, N)

In the SK model the Binder cumulant stays between \(0.8\) and \(0.85\) at the lowest temperature (the weight between the peaks of \(P(q)\)), and the error decreases slowly and smoothly, only to about \(0.5\).

The histogram detector behaves alike in both models: in the Mattis model, too, its alarm goes off above \(T_c\), at a temperature that increases with \(N\). The Curie–Weiss transition is also a mean-field transition, with a susceptibility \(1/(1-\beta J)\) that grows continuously as \(T\) approaches \(J\) from above. The onset of an anomaly score measures where fluctuations become noticeable at the given resolution, not the critical temperature.

Both data sets have uniformly random single snapshots and both have random-sign couplings. The difference that the overlap-based detectors see, a broad \(P(q)\) that stays broad, is the signature of frustration.

The order of the spin glass is invisible in single snapshots, and no learning method can change this: the gauge symmetry makes the data uniform. The right input, the overlap of two replicas, was found by physicists through the replica theory; given it, PCA finds the overlap as its first component and the autoencoder learns \(q^2\). Neither locates \(T_c\) by itself. The PCA projection becomes a measurement of \(T_c\) only through the finite-size scaling of its Binder cumulant, with the same wide intervals as the physicist’s analysis, and the anomaly onsets reflect the smooth growth of fluctuations of a mean-field transition rather than its location. Supervised work on the three-dimensional Edwards–Anderson spin glass reached the same conclusion about the input: Munoz-Bauza, Hamze and Katzgraber fed a convolutional network with replica overlap configurations, not with spins.

Exercise 1 — The covariance of an exchangeable distribution

Assume the pooled overlap fields have a distribution symmetric under permutations of the labels and under \(\boldsymbol q\to-\boldsymbol q\). (a) Show that the covariance matrix is \(C=(1-c)\,\mathbb 1+c\,\boldsymbol 1\boldsymbol 1^T\) with \(c=(N\overline{q^2}-1)/(N-1)\). (b) Find all eigenvalues. (c) Compare with the PCA of Section 3.2 for \(N=128\): \(\sigma_1^2\) and the mean of the other eigenvalues.

Solution

  1. The diagonal entries are \(\overline{q_i^2}=1\); by symmetry all off-diagonal entries are equal to \(c\). Summing all entries, \(\sum_{ij}\overline{q_iq_j}=N^2\overline{q^2}=N+N(N-1)c\), which gives \(c\). (b) \(C\boldsymbol 1=(1-c+Nc)\boldsymbol 1\), so \(\sigma_{\rm uniform}^2=1+(N-1)c=N\overline{q^2}\); every vector orthogonal to \(\boldsymbol 1\) has eigenvalue \(1-c=N(1-\overline{q^2})/(N-1)\), \(N-1\) times. (c) The code compares these with the measured spectrum. Small differences in \(\sigma_1^2\) come from the centring of PCA and the factor \(M/(M-1)\); the other eigenvalues of the data scatter around their mean, which is fixed by the trace, because the finite set of samples is only approximately exchangeable.

Solution

With four numbers the error falls well below \(1-[\langle q^2\rangle]\).
